## 什么时候可以新增一行

一条记录必须在结果可见前登记，并且保留以下冻结字段：

1. **判断 ID 与冻结时间**：例如 `J-NNN`；记录卡面冻结日期和信息截止点（`as-of`）。
2. **预测内容**：原始中英文判断文本，或指向冻结卡面的稳定链接；结果揭晓后不得静默改写。
3. **观察窗**：开始日、结束日、到期判定日，以及结果何时被揭晓。
4. **领先指标**：预先登记的指标、单位、频率、数据来源和判定方向。
5. **受众规模**：受影响人群的身份、数量级与行为分母；影响面不能替代重复执行人数。
6. **到期判定**：`HIT`、`FALSIFIED` 或 `INDETERMINATE` 的预登记规则；无法计算时必须说明缺失量，不得改写条件制造结果。
7. **结果证据**：原始来源的稳定 URL／文件定位、抓取或访问日期、同口径摘录、单位、分母和必要的哈希或版本信息。
8. **状态**：登记后为 `PENDING`；观察窗结束并完成证据审查后才可改为 `HIT`、`FALSIFIED` 或 `INDETERMINATE`。`UNKNOWN/UNVERIFIED` 表示证据链尚未闭合，不是命中或失准。

结果复核必须在观察窗结束后进行，并把判断当时的冻结文本与结果侧证据并列展示。若结果证据不足，记录 `INDETERMINATE` 并保留缺口；它仍进入到期复核记录，但不自动进入准确率分子或分母。

## 复核纪律

- 以台账预登记的时间窗、证伪条件和下次检查日生成到期集合，不按结果倒推集合。
- 到期不是自动 `HIT`；必须逐条读取冻结卡、依赖项、领先指标和结果证据。
- 一次复核若发现多数卡的证伪条件不可判定，或判断被静默改写以适配已发生事实，须把它作为方法失败信号写入[判断演化记录](../zh/03-evolution.md)，而不是删除不利记录。
- 中文与英文登记必须在同一次 commit 更新；commit message 应写明判断 ID、结果变化和新证据。
- `python3 scripts/check.py` 或 `npm run check` 只证明结构与链接，不会把本页的空状态升级为未来样本外证据。

本页的空状态将随着第一批真实到期复核而改变；在此之前，项目不报告未来准确率。
