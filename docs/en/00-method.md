# Foresight Method

> This file defines how the project reasons. Concrete judgments live in the chains and ledger.

## First principles

We reason from supply and demand, persistent human motives, historical diffusion patterns, technology constraints, and social responses. We do not use another institution's prediction as an argument. Because a language model carries remembered consensus, overlaps are marked explicitly as **consistent with consensus**.

## Lenses

- **L1 Abundance → scarcity:** when one input becomes cheap, value moves to its constrained complements.
- **L2 Constraint migration:** removing one bottleneck moves the bottleneck elsewhere.
- **L3 Cost structure:** coordination and transaction costs shape organizations.
- **L4 Diffusion lag:** capability, adoption, regulation, and skills move on different clocks.
- **L5 Signals and forgery:** when a signal becomes cheap to fake, screening seeks a costlier signal.
- **L6 Irreversibility:** cheap generation helps only where mistakes can be undone.
- **L7 Institutional lag:** rules trail technology and create temporary rents.
- **L8 Human constants:** status, loss aversion, embodied presence, and responsibility persist.

Each chain states which lenses it uses and why.

## The gate

For every new scarcity ask: can the same force that made the original thing abundant automate this scarcity too? If yes, label it a **window** rather than a structural opportunity. If no, name the hard constraint: physical presence, law/liability, trust and repeated relationships, ownership, embodiment, or irreversibility.

## Judgment card

Each usable judgment needs: `J-NNN`; layer; lenses; reasoning chain; time window; falsifier; leading indicator; confidence; dependencies; consensus comparison; and status (`ACTIVE`, `HIT`, `FALSIFIED`, `REVISED`). Missing fields mean “landscape only.”

## Time layers and writing

Near (2026–2029) is mainly a speed question; mid (2029–2033) is mainly an institutional response question; far (2033–2041) includes possible preference drift and is usually landscape only. Layers are coarse containers, not strict chronology. The `depends-on` graph carries causal order.

Every chain begins with a concrete scene, explains its mechanism, says what can be done now, and ends with the strongest opposing mechanism. The Chinese and English versions share judgment IDs and land in the same commit.
