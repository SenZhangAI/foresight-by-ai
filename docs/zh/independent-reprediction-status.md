## 这页为什么存在

项目在历史校准之后，按既定顺序把旧预测材料送入隔离式重审：不是让一个新实例直接阅读带有旧状态的台账，而是先冻结输入，再生成去标签、重编号、乱序的 bundle，由 fresh-context 批次逐条重判，最后才解封映射。

这页是面向公开读者的状态入口。它不创建新的未来判断，也不替代[判断台账](90-ledger.md)、[历史伪样本外验证协议](02-historical-validation-protocol.md)或[隔离盲判复审报告](../evidence/blind-review-reaudit-2026-10-09.md)。它是当前证据状态的导航页，不是把历史重审升级为未来样本外预测的凭证。

## 本轮实际完成了什么

1. **冻结了可追溯输入**：记录来源提交、manifest、纳入规则、卡片数量、中英文投影和哈希，避免在看到结果后随意增删卡片。
2. **物化了流程隔离**：先交结果、后解封映射；各批次不能看见其他批次或仓库全文。生成器的负例检查也记录在 bundle 证据页中。
3. **修复并补判了输入缺陷**：首轮发现 28 张卡的一句话判断因标题去标签规则被清空。没有把它们永久排除，而是修复生成器后用第二轮补判；首轮处置只保留为历史记录。
4. **保留了限制而非抹平限制**：受众字段泄漏、缺运行时间、第二轮哈希先后顺序依赖负责人背书、同模型训练记忆等边界都公开记录。

完整逐卡理由、两轮历史口径、五卡补充调试批次、缺口和禁止表述见[隔离盲判复审报告](../evidence/blind-review-reaudit-2026-10-09.md)与[补充闸筛查留痕](../evidence/independent-reprediction-supplement-2026-10-27.md)；协议层的证据标签和下一步条件见[历史伪样本外验证协议](02-historical-validation-protocol.md)。
