### J-021 · 一手现场信号先获得溢价
- **历史迁移**：[逐卡历史迁移清单 · J-021](../../evidence/legacy-ledger-migration.md#j-021)；原始卡快照固定于 Git `1f99c832be8cbc82631beb7679d82994a2b7e0fb^`，当前卡不覆盖该快照。

- **提出日期**：2026-09-18
- **一句话判断**：2026–2029 年，未经记录的现场观测和可追溯来源会比二手表达更早获得溢价。
- **受众规模**：基于现有普及闸复核重建：千万量级（高责任行业的专业者与采购者），周频；提高既有专业者上限；历史卡没有独立字段，非独立统计。
- **普及闸复核**：受众规模＝千万量级（高责任行业的专业者与采购者），周频；闸一**不过**——按普及闸降级为职业／组织性判断，不得以「整个社会」「普遍」「成为风气」的口吻引用。
- **所以现在可以做什么**: 可立即测量／试点：围绕本卡“领先指标”建立基线或在其限定受众与场景内做小范围试点；不得把测量结果提前写成已验证趋势或超出证据边界的商机。
- **透镜**：丰富→稀缺 + L5 信号伪造。
- **推理链**：J-005 的原始信号不可由重组生成 → J-015 让二手表达更易自动筛选 → 买方把溢价转向现场、来源与责任。
- **时间窗**：2026–2029。
- **证伪条件**：到 2029 年，买方对可验证现场与高保真重组不再支付差异化价格。
- **领先指标**：带时间地点来源的资料成交溢价、现场数据采购合同数；每半年观察。
- **置信度**：中
- **depends-on**：J-005, J-015。
- **最强反方**：高保真模拟获得制度与市场认可，足以替代现场观测；若替代在多个领域稳定出现，本判断撤回。
- **与共识**：部分一致：可追溯的一手来源可能先升值；分歧与证据边界：尚无普遍现场溢价的价格证据。我为何仍坚持：在高责任任务中，合成表达和二手转述更容易复制，来源与责任链会成为更难伪造的信号，因此即使普遍溢价尚未出现，局部溢价仍有机制基础。
- **外部对照来源**：EXT-4, EXT-11（见上方来源索引）。
- **出处**：[近期图景](../10-near.md)。
- **下次检查日**：2027-06-30。

### J-022 · 可伪造信号推动凭据升级
- **历史迁移**：[逐卡历史迁移清单 · J-022](../../evidence/legacy-ledger-migration.md#j-022)；原始卡快照固定于 Git `1f99c832be8cbc82631beb7679d82994a2b7e0fb^`，当前卡不覆盖该快照。

- **提出日期**：2026-09-18
- **一句话判断**：2026–2029 年，可伪造的个性化信号增加后，重要判断会转向更昂贵的身份、履约和责任凭据。
- **受众规模**：基于现有普及闸复核重建：亿量级（专业服务、平台与组织采购者），周频；提高既有专业者上限；历史卡没有独立字段，非独立统计。

- **透镜**：丰富→稀缺 + L5 信号伪造。
- **推理链**：J-005 使可追责主体升值 → J-017 使弱关系协调变便宜 → 表面互动更难区分 → 高价值决策提高凭据门槛。
- **时间窗**：2026–2029。
- **证伪条件**：高价值交易中，低成本生成身份信号的接受率上升且没有额外责任或验证要求。
- **领先指标**：多因素凭据采用率、保证金与责任条款的交易占比；每半年观察。
- **置信度**：中
- **depends-on**：J-005, J-017。
- **最强反方**：平台能低成本提供可信身份和赔付，凭据升级不增加买方成本；若平台内置验证后门槛下降，本判断重审。
- **与共识**：与“信任更重要”方向一致，但机制偏向来源、身份与责任凭据升级；采用率和成本仍未知。仍坚持：可伪造信号增加必然抬高高价值判断的验证门槛，这由信号伪造机制决定；采用率与成本未知，因此置信度保持「中」。
