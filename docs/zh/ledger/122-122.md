# 判断卡片 J-122

[English version](../../en/ledger/122-122.md)

本分片登记 C16「文化、环境与日常承载」的交通与日常出行卡片。它不把现有具身智能卡片重复计为交通覆盖，也不把单一交通方式写成必然赢家。

### J-122 · 日常出行先按可靠性与照护责任分层，而不是自动转向单一方式

- **提出日期**：2026-10-22
- **一句话判断**：2027–2035 年，在有可比数据的高收入城市，通勤、照护和购物出行更可能按可靠性、可负担性、居住密度与照护责任分层；低收入家庭和需要频繁照护出行的家庭先承受等待、换乘与出行中断成本，而不是全体自动转向某一种交通方式。
- **受众规模**：受影响人口＝城市通勤者、照护者、儿童与老年人家庭、公共交通使用者和地方交通管理者，十亿量级影响面；实际重复执行者／行为分母＝每周至少一次通勤、照护或购物出行的去重成年人及其家庭，当前没有跨城市统一分母，不能声称十亿级周频动作；能力类型＝不适用，不提高既有专业者上限，也不让原本不会的人也能做。
- **所以现在可以做什么**：城市交通或公共服务负责人：两周内抽取 20 个家庭的通勤、照护和购物出行记录，分别记录等待、换乘、费用、取消原因、替代路线与照护对象；看什么（挂在「领先指标」）：按收入组与照护责任分组的可靠性、总出行时间、费用／收入比、服务中断天数、照护出行可达率和方式组合；先看 20 个家庭的逐次记录，城市总量只作背景。
- **透镜**：L1（供需关系）、L4（历史规律）、L5（社会规律）、L6（技术规律的物理约束部分）、L7（制度与权力）、L8（人性中的风险与责任）；技术只是交通承载方式之一，不是起点。
- **推理链**：居住分布与照护责任固定了必须发生的出行 → 道路容量、公共交通班次、能源价格和极端天气共同改变可靠性与成本 → 时间余量更少、照护责任更高的家庭先吸收等待、换乘与取消风险 → 家庭会组合多种方式并调整活动半径，而不是因为某项技术出现就同步换成一种方式 → 交通不平等首先表现为可可靠到达的机会差异。
- **时间窗**：2027-01-01 至 2035-12-31
- **证伪条件**：在预注册的至少 12 个高收入城市中，若相对 2024–2026 基线，连续三年各收入组和照护责任组的出行可靠性、可负担性与照护出行可达率同步改善至少 10%，且方式组合差异与取消／中断差异不扩大，则“可靠性与照护责任造成分层、而非单一方式替代”的方向被证伪；缺少统一家庭分母或分组数据时记为不可判定。
- **领先指标**：按收入与照护责任分组的准点率、等待与换乘时间、出行费用／收入比、道路与公共交通中断天数、照护出行可达率、方式组合和取消率；季度／年度。
- **置信度**：低
- **depends-on**：J-096, J-109, J-113
- **最强反方**：密集型住房、免费或低价公共交通、远程服务与可靠的自动驾驶接驳可能同时降低等待和照护出行成本，使不同家庭的可达性差异缩小；能源价格下降也可能让私人交通维持可负担。
- **与共识**：本轮未完成外部对照；独立推演暂不把电动化、自动驾驶或公共交通扩张写成全体自动换方式，保留可靠性、可负担性与照护责任造成分层的窄判断；跨城市家庭分母和长期面板待补。
- **外部对照来源**：本轮未完成；无独立外部来源登记。
- **外部对照状态（2026-10-22）**：`UNVERIFIED`；独立推演已登记，但尚未完成跨城市可比资料对照；不得把本卡写成外部验证。下一步：按本卡领先指标建立共同家庭分母，并补充城市面板后复核置信度。
