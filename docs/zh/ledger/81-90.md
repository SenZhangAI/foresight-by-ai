### J-081 · 药物候选更丰富，不等于人体试验时间同步缩短
- **历史迁移**：[逐卡历史迁移清单 · J-081](../../evidence/legacy-ledger-migration.md#j-081)；原始卡快照固定于 Git `1f99c832be8cbc82631beb7679d82994a2b7e0fb^`，当前卡不覆盖该快照。

- **提出日期**：2026-09-21
- **一句话判断**：到 2034 年，AI 增加进入实验室的药物候选，但候选增长不会等比例转化为获批药物。
- **受众规模**：构造式百万量级研发、试验与监管执行者；主要是**提高既有专业者上限**（非可引用行为统计）。；该字段从同卡现有普及闸复核重建，不是历史卡的独立统计。
- **普及闸复核**：直接动作由构造式百万量级研发、试验和监管参与者完成，不是可引用行为统计；闸一**不过**。**闸一第二问**：提高既有药物研发者的搜索上限，不让原本不会做湿实验或人体试验的人独立完成研发闭环。
- **所以现在可以做什么**: 行动：药企或 CRO 里负责临床试验运营的负责人——两周内从自己的试验管理系统导出近几年进入 I 期的全部候选，按“AI 起源／传统来源”分两组，逐个记下从方案定稿到首个站点启动、再到招募完成各用了几周，以及是否因站点、受试者名额或伦理审查排期而推迟。看什么：若 AI 起源组的站点启动与招募耗时与传统组相当甚至更长、排队待启动的候选越积越多，你们这批候选与判断相符；若 AI 起源组借生物标志物筛选或适应性设计明显缩短了招募与随访，则指向最强反方与证伪条件（对应领先指标）。
- **透镜**：L2 约束迁移 + 成本结构（2026-10-10 标注：此处「成本结构」与 L3 同名，但本卡推理链推的是更多候选争夺没有同比扩张的人体试验产能、排队上升，没有运行 L3「组织的边界由协调成本和交易成本塑造」，按 L 代号反查时不计为 L3；[C5](../chains/50-biology-medicine.md) 页首据此把 L3 记为「卡片名义声明、机制未运行」）。
- **推理链**：搜索空间扩大 → 更多候选争夺没有同比扩张的湿实验、受试者、站点与监管容量 → 淘汰率或排队上升。
- **时间窗**：2026–2034。
- **证伪条件**：2028–2034 年，AI 起源候选从首次人体试验到获批的中位历时与失败率同时下降 50% 以上，并在至少三个治疗领域复现。
- **领先指标**：AI 起源候选的 Phase I 数量、各期转化率、站点启动与招募完成时间、每个获批药对应的临床候选数；每年。
- **置信度**：中
- **depends-on**：J-079, J-066。
- **最强反方**：预测性生物标志物、适应性试验和数字终点可能同时减少样本与随访。
- **与共识**：**一致**：FDA 要求按风险建立 AI 可信度。**边界**：不支持周期或成功率预测。**我为何仍坚持**：候选计算与人体时间属于不同生产函数。
- **外部对照来源**：EXT-49。
- **出处**：[C5：生物与医疗](../chains/50-biology-medicine.md)。
- **下次检查日**：2027-06-30。
- **隔离盲判复审（2026-10-09）**：盲判编号 R1-48，裁定 `ABSTAIN`，无闸位被判否；处置「保留·盲判未否决（闸只能判否，不得据此上调）」。判据、缺证原文与边界见[隔离盲判复审](../../evidence/blind-review-reaudit-2026-10-09.md)。
- **状态**：ACTIVE

### J-082 · 解释变多后，医疗稀缺移向获授权的干预与连续照护（仅图景）
- **历史迁移**：[逐卡历史迁移清单 · J-082](../../evidence/legacy-ledger-migration.md#j-082)；原始卡快照固定于 Git `1f99c832be8cbc82631beb7679d82994a2b7e0fb^`，当前卡不覆盖该快照。

- **提出日期**：2026-09-21
- **一句话判断**：2027–2034 年，慢病、老龄和基层医疗的瓶颈从标准解释移向获授权干预、连续观察和异常升级。
- **受众规模**：受影响人口为构造式十亿量级患者影响面；实际重复执行者／行为分母是 T 时每周完成一次采样、给药、复诊或异常升级的去重照护者／医护，不是患者总数；本卡没有全球统一的该分母、动作频次或来源，因此十亿只能写影响面；主要是**提高既有专业者上限**（均非可引用行为统计）。；该字段从同卡现有普及闸复核重建，不是历史卡的独立统计。
- **普及闸复核**：受影响患者为构造式十亿量级，直接执行者为构造式千万至亿量级照护者与医护；均非可引用行为统计，属制度／职业安排，闸一**不过**。**闸一第二问**：提高既有照护者与医护的解释和监测上限，不让原本不会实施获授权干预的人独立完成连续照护。
- **所以现在可以做什么**: 仅图景：判断讲的是慢病、老龄与基层医疗的瓶颈在多国、多年里从解释移向获授权干预与连续照护，一家诊所两周的记录分不清“AI 解释催生的待兑现需求”与原有的人手短缺，也排除不了远程监测让连续照护可扩展的反方。缺什么：能把“患者是否先收到 AI 解释或提醒”与其后复诊完成、异常升级时延连起来的随访记录，配上按每位照护者折算的负担分母，并在几个国家的基层系统间逐年可比。谁能先补：已在做慢病随访的基层医疗网络质控部门——在随访登记表加一项“本次就诊是否由 AI 建议触发”，并记下其后的复诊与升级时间。
- **透镜**：L2 约束迁移 + 身体在场硬约束。
- **推理链**：问答可复制 → 解释与提醒边际成本下降 → 采样、给药、转移、复诊与异常判断仍需本地资源和责任链 → 无载体时建议变成未兑现需求。
- **时间窗**：2027–2034。
- **证伪条件**：多个国家在 AI 问答广泛使用五年内，可干预工时、随访完成率和异常响应速度同步增长，且人力与机构容量不再是主要排队原因。
- **领先指标**：建议后复诊完成率、异常升级时延、每位照护者负担、基层空缺岗位、远程项目十二个月留存；每年。
- **置信度**：低（仅图景）
- **depends-on**：J-079, J-080, J-032, J-066。
- **最强反方**：远程监测、家庭机器人与任务重构可能使连续照护本身可扩展。
- **与共识**：**一致**：WHO 支持卫生人力、问责和安全是现实约束。**边界**：不证明 AI 会加剧照护排队。**我为何仍坚持**：本地干预与责任链不会由更多解释自动生成。
- **外部对照来源**：EXT-50, EXT-51。
- **出处**：[C5：生物与医疗](../chains/50-biology-medicine.md)。
- **下次检查日**：2027-12-31。
- **隔离盲判复审（2026-10-09）**：盲判编号 R1-86，裁定 `ABSTAIN`，无闸位被判否；处置「保留·盲判未否决（闸只能判否，不得据此上调）」。判据、缺证原文与边界见[隔离盲判复审](../../evidence/blind-review-reaudit-2026-10-09.md)。

### J-083 · 个性化讲解先于可验证掌握变丰富
- **历史迁移**：[逐卡历史迁移清单 · J-083](../../evidence/legacy-ledger-migration.md#j-083)；原始卡快照固定于 Git `1f99c832be8cbc82631beb7679d82994a2b7e0fb^`，当前卡不覆盖该快照。

- **提出日期**：2026-09-21
- **一句话判断**：2026–2030 年，个性化解释、例题和即时反馈成为常规能力，但可验证掌握不同比增长。
- **受众规模**：受影响人口为构造式十亿量级学习者影响面；实际重复执行者／行为分母应是 T 时每周至少一次完成同一 AI 辅导动作（例如提交练习并接受反馈）的去重学习者；本卡没有十亿级该动作统计、去重口径或来源，因此十亿只能写影响面，学习可达日频；既**提高既有专业者上限**，也可能让部分原本得不到个性化讲解的人获得该动作。；该字段从同卡现有普及闸复核重建，不是历史卡的独立统计。
- **普及闸复核**：全球学习者的影响面为构造式十亿量级、学习可达日频，但没有可引用统计证明十亿个不同个人每日执行同一种 AI 辅导动作；闸一**不过**，按学习场景判断书写。**闸一第二问**：既提高既有学习者获取反馈的上限，也让原本得不到个性化讲解的人获得该能力；是否转化为掌握另受本卡证伪条件约束。
- **所以现在可以做什么**: 行动：中学数学教研组长——在两周内的下一次单元测验里加三道学生在 AI 讲解和练习中都没见过的变式题，闭卷独立完成；按 AI 辅导平台的使用记录（没有平台就让学生自报）把学生分成高、低两组，对比两组的练习正确率、变式题得分和求助次数，并约定三个月后用同类题复测。看什么：若高使用组练习正确率明显更高，变式题与复测得分却不同比领先、求助依赖更重，说明在你的学生里“看懂”与“独立完成”在分叉，与判断相符；若不改课程设计，变式题与复测成绩就随使用强度同比提高，则指向证伪条件（对应领先指标）。
- **透镜**：L2 约束迁移 + 普及闸。
- **推理链**：讲解可复制 → 生成与翻译成本下降 → 练习仍要求注意、时间与行为改变 → “看懂”与“独立完成”分叉。
- **时间窗**：2026–2030。
- **证伪条件**：多国、多年龄、多学科中，广泛使用生成式辅导两年后，受控迁移测试与长期保持率按使用强度同比提高且无需课程重设。
- **领先指标**：AI 辅导周活、独立迁移成绩、三至六个月保持率、完成率与帮助依赖度；每学期。
- **置信度**：中
- **depends-on**：J-001, J-066。
- **最强反方**：自适应辅导可能同时改善反馈、节奏与动机，使解释直接转化为掌握。
- **与共识**：**一致**：UNESCO 要求人本、年龄适配、隐私和教学设计。**边界**：不证明学习成果不会同比提高。**我为何仍坚持**：练习时间不可由解释替学员承担。
- **外部对照来源**：EXT-52。
- **出处**：[C6：教育与技能形成](../chains/60-education-skill-formation.md)。
- **下次检查日**：2027-06-30。

### J-084 · AI 辅导先嵌入教师与机构，而不是替代学校
- **历史迁移**：[逐卡历史迁移清单 · J-084](../../evidence/legacy-ledger-migration.md#j-084)；原始卡快照固定于 Git `1f99c832be8cbc82631beb7679d82994a2b7e0fb^`，当前卡不覆盖该快照。

- **提出日期**：2026-09-21
- **一句话判断**：2026–2031 年，AI 辅导先在教师布置、课程对齐和机构监督中稳定扩散，而非大规模替代学校。
- **受众规模**：构造式十亿量级学生与在职学习者影响面、学习可达周频；主要**提高既有专业者上限**，动作主体仍为学校／雇主载体。；该字段从同卡现有普及闸复核重建，不是历史卡的独立统计。
- **普及闸复核**：学生与在职学习者虽是构造式十亿量级、学习可达周频，但没有可引用行为统计，且判断对象是学校／雇主是否成为载体，而不是学生执行的同一动作；闸一**不过**，按制度性判断书写。**闸一第二问**：主要提高既有教师与机构的辅导上限，不等于让原本不会办学、评价或授予资格的人获得这些权力。
- **所以现在可以做什么**: 行动：中学或职业院校分管教学信息化的教务主任——两周内借一次班会问卷，列出学生本学期在用的全部 AI 辅导工具，逐项标出是“教师布置、与校内课程或学习平台打通”还是“学生或家长自购”，以及是否一年前就在用；同时请任课教师记下每周花在配置和批阅 AI 作业上的时数。看什么：若用满一年仍在用的主要是教师布置且接入课程的工具、自购工具多半弃用，你校的问卷结果与判断相符；若自购工具留存更高，且学生开始拿校外 AI 路径取得的证书申请免修或替代校内成绩，则指向最强反方与证伪条件（对应领先指标）。
- **透镜**：L4 扩散滞后 + 普及闸三至闸五。
- **推理链**：独立聊天增加新动作 → 机构内辅导替换答疑、练习与反馈 → 学校提供身份、课程、同伴、评价和资格载体 → 局部闭环先扩散。
- **时间窗**：2026–2031。
- **证伪条件**：到 2031 年，至少三个大型教育系统中，脱离学校／雇主的 AI 路径获得的普遍认可资格持续多于机构内路径。
- **领先指标**：教师布置型与个人直购型使用占比、课程系统集成、十二个月留存、教师工作量、独立 AI 资格认可范围；每年。
- **置信度**：中
- **depends-on**：J-083, J-066, J-068, J-069, J-070, J-071。
- **最强反方**：学校成本、地域缺口和成人需求可能让直面学习者的系统绕过机构。
- **与共识**：**一致**：OECD 强调治理、生态和教师能力。**边界**：不证明学校保持当前边界。**我为何仍坚持**：学校绑定了学习之外的身份、评价与资格出口。
- **外部对照来源**：EXT-53。
- **出处**：[C6：教育与技能形成](../chains/60-education-skill-formation.md)。
- **下次检查日**：2027-06-30。
- **隔离盲判复审（2026-10-09）**：盲判编号 R1-77，裁定 `ABSTAIN`，无闸位被判否；处置「保留·盲判未否决（闸只能判否，不得据此上调）」。判据、缺证原文与边界见[隔离盲判复审](../../evidence/blind-review-reaudit-2026-10-09.md)。

### J-085 · 居家成品信号变弱，受控表现与过程证据增值
- **历史迁移**：[逐卡历史迁移清单 · J-085](../../evidence/legacy-ledger-migration.md#j-085)；原始卡快照固定于 Git `1f99c832be8cbc82631beb7679d82994a2b7e0fb^`，当前卡不覆盖该快照。

- **提出日期**：2026-09-21
- **一句话判断**：2027–2034 年，高风险升学和招聘降低无过程验证居家成品的权重，增加受控表现与过程证据。
- **受众规模**：构造式亿量级考生、求职者与学习者影响面；主要**提高既有专业者上限**，评价动作低频且主体为学校／雇主。；该字段从同卡现有普及闸复核重建，不是历史卡的独立统计。
- **普及闸复核**：直接影响面为构造式亿量级考生、求职者和学习者，不是可引用行为统计且动作低频；闸一**不过**，按制度性判断书写。**闸一第二问**：改变既有学校与雇主的筛选上限和证据结构，不让原本没有录取或雇佣权的人获得资格授予权。
- **所以现在可以做什么**: 行动：考试机构里负责课程作业（居家完成部分）与受控笔试配比的评价设计人员——两周内调出近几届同一批考生的课程作业分和受控考试分，按生成式 AI 普及前后分组算两者的相关程度，并抽查作业有无过程稿或版本记录。看什么：若普及后几届作业分整体上移、与受控考试分的相关明显变弱，说明无过程验证的成品正失去与能力的相关，下一轮规格修订提高口试与现场任务比重或要求版本史就有依据，这批考生的成绩与判断相符；若相关并未下降，则指向证伪条件；若过程稿也大批雷同，则对应最强反方所说过程记录可伪造（对应领先指标）。
- **透镜**：L5 信号博弈 + L1 丰富→稀缺。
- **推理链**：成品生成成本下降 → 成品与本人能力相关性变弱 → 选择者转向更贵但更难转包的身份、现场和长期记录。
- **时间窗**：2027–2034。
- **证伪条件**：到 2032 年，主要大学与大型雇主仍扩大无过程验证居家成品的独立权重，且其对后续表现的预测效度不降。
- **领先指标**：口试和现场任务占比、身份验证支出、作品集版本史要求、实习／学徒记录权重；每年。
- **置信度**：中

- **所以现在可以做什么**: 行动：持有牌照与存量客户的保险公司或券商里负责经营分析的财务负责人——两周内调出近四个季度已上线的 AI 项目，把每个项目实测节省的成本拆成四个去向：付给模型与云供应商、留作本公司利润、以降价降费让给客户、以工资奖金分给员工；再从渠道数据查同期有多少客户转向 AI 原生的新进入者。看什么：若节省大部分留在本公司利润、客户流失未见加速，你公司这四个季度与收益先流向互补资产所有者相符；若节省多被竞争压成降价、被供应商费用吃掉大半，或客户成批转向小团队，则指向证伪条件与最强反方（对应领先指标）。
- **透镜**：互补资产 + 资本收益 + 竞争制度。
- **推理链**：模型和调用价格下降 → 核心能力租金受压 → 商业化仍需稀缺互补资产与固定改造成本 → 既有资产拥有者先吸收收益 → 开放标准、竞争与再分配决定后续扩散。
- **时间窗**：2027–2035。
- **证伪条件**：到 2032 年，在至少五个高采用行业中，控制客户、专有数据、牌照、渠道或基础设施的既有企业并未获得相对利润率、市场份额或议价权改善；无论收益转向新进入者、模型供应商、劳动者还是消费者，均触发本卡证伪。
- **领先指标**：行业利润率、并购与集中度、AI 供应链各层收益、工资份额、价格下降、数据可携带性与渠道迁移率；每年。

- **depends-on**：J-001, J-039, J-056, J-087。
- **最强反方**：模型商品化、开放权重与低代码分发可能使互补资产快速可复制，小团队直接夺走既有渠道和利润。
