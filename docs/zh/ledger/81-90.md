### J-081 · 药物候选更丰富，不等于人体试验时间同步缩短
- **历史迁移**：[逐卡历史迁移清单 · J-081](../../evidence/legacy-ledger-migration.md#j-081)；原始卡快照固定于 Git `1f99c832be8cbc82631beb7679d82994a2b7e0fb^`，当前卡不覆盖该快照。

- **提出日期**：2026-09-21
- **一句话判断**：到 2034 年，AI 增加进入实验室的药物候选，但候选增长不会等比例转化为获批药物。
- **受众规模**：构造式百万量级研发、试验与监管执行者；主要是**提高既有专业者上限**（非可引用行为统计）。；该字段从同卡现有普及闸复核重建，不是历史卡的独立统计。
- **普及闸复核**：直接动作由构造式百万量级研发、试验和监管参与者完成，不是可引用行为统计；闸一**不过**。**闸一第二问**：提高既有药物研发者的搜索上限，不让原本不会做湿实验或人体试验的人独立完成研发闭环。
- **所以现在可以做什么**: 可立即测量／试点：围绕本卡“领先指标”建立基线或在其限定受众与场景内做小范围试点；不得把测量结果提前写成已验证趋势或超出证据边界的商机。
- **透镜**：L2 约束迁移 + 成本结构。
- **推理链**：搜索空间扩大 → 更多候选争夺没有同比扩张的湿实验、受试者、站点与监管容量 → 淘汰率或排队上升。
- **时间窗**：2026–2034。
- **证伪条件**：2028–2034 年，AI 起源候选从首次人体试验到获批的中位历时与失败率同时下降 50% 以上，并在至少三个治疗领域复现。
- **领先指标**：AI 起源候选的 Phase I 数量、各期转化率、站点启动与招募完成时间、每个获批药对应的临床候选数；每年。
- **置信度**：中
- **depends-on**：J-079, J-066。
- **最强反方**：预测性生物标志物、适应性试验和数字终点可能同时减少样本与随访。
- **与共识**：**一致**：FDA 要求按风险建立 AI 可信度。**边界**：不支持周期或成功率预测。**我为何仍坚持**：候选计算与人体时间属于不同生产函数。
- **外部对照来源**：EXT-49。
- **出处**：[C5：生物与医疗](../chains/50-biology-medicine.md)。
- **下次检查日**：2027-06-30。
- **状态**：ACTIVE

### J-082 · 解释变多后，医疗稀缺移向获授权的干预与连续照护（仅图景）
- **历史迁移**：[逐卡历史迁移清单 · J-082](../../evidence/legacy-ledger-migration.md#j-082)；原始卡快照固定于 Git `1f99c832be8cbc82631beb7679d82994a2b7e0fb^`，当前卡不覆盖该快照。

- **提出日期**：2026-09-21
- **一句话判断**：2027–2034 年，慢病、老龄和基层医疗的瓶颈从标准解释移向获授权干预、连续观察和异常升级。
- **受众规模**：受影响人口为构造式十亿量级患者影响面；实际重复执行者／行为分母是 T 时每周完成一次采样、给药、复诊或异常升级的去重照护者／医护，不是患者总数；本卡没有全球统一的该分母、动作频次或来源，因此十亿只能写影响面；主要是**提高既有专业者上限**（均非可引用行为统计）。；该字段从同卡现有普及闸复核重建，不是历史卡的独立统计。
- **普及闸复核**：受影响患者为构造式十亿量级，直接执行者为构造式千万至亿量级照护者与医护；均非可引用行为统计，属制度／职业安排，闸一**不过**。**闸一第二问**：提高既有照护者与医护的解释和监测上限，不让原本不会实施获授权干预的人独立完成连续照护。
- **所以现在可以做什么**: 仅图景：当前只能保留图景、继续观察本卡“领先指标”与证伪条件；在证据边界收窄前，不把它当作已验证趋势、社会级结论或商机。
- **透镜**：L2 约束迁移 + 身体在场硬约束。
- **推理链**：问答可复制 → 解释与提醒边际成本下降 → 采样、给药、转移、复诊与异常判断仍需本地资源和责任链 → 无载体时建议变成未兑现需求。
- **时间窗**：2027–2034。
- **证伪条件**：多个国家在 AI 问答广泛使用五年内，可干预工时、随访完成率和异常响应速度同步增长，且人力与机构容量不再是主要排队原因。
- **领先指标**：建议后复诊完成率、异常升级时延、每位照护者负担、基层空缺岗位、远程项目十二个月留存；每年。
- **置信度**：低（仅图景）
- **depends-on**：J-079, J-080, J-032, J-066。
- **最强反方**：远程监测、家庭机器人与任务重构可能使连续照护本身可扩展。
- **与共识**：**一致**：WHO 支持卫生人力、问责和安全是现实约束。**边界**：不证明 AI 会加剧照护排队。**我为何仍坚持**：本地干预与责任链不会由更多解释自动生成。
- **外部对照来源**：EXT-50, EXT-51。
- **出处**：[C5：生物与医疗](../chains/50-biology-medicine.md)。
- **下次检查日**：2027-12-31。

- **推理链**：讲解可复制 → 生成与翻译成本下降 → 练习仍要求注意、时间与行为改变 → “看懂”与“独立完成”分叉。

### J-084 · AI 辅导先嵌入教师与机构，而不是替代学校

- **推理链**：独立聊天增加新动作 → 机构内辅导替换答疑、练习与反馈 → 学校提供身份、课程、同伴、评价和资格载体 → 局部闭环先扩散。

- **证伪条件**：到 2031 年，至少三个大型教育系统中，脱离学校／雇主的 AI 路径获得的普遍认可资格持续多于机构内路径。

- **depends-on**：J-083, J-066, J-068, J-069, J-070, J-071。
- **最强反方**：学校成本、地域缺口和成人需求可能让直面学习者的系统绕过机构。
- **与共识**：**一致**：OECD 强调治理、生态和教师能力。**边界**：不证明学校保持当前边界。**我为何仍坚持**：学校绑定了学习之外的身份、评价与资格出口。

- **一句话判断**：2026–2031 年，采用生成与工具调用的组织先把工作拆成机器默认执行、人类处理例外、责任人设定边界，而不是普遍形成无人组织。
- **受众规模**：受影响人口为构造式亿量级知识工作者、运营人员与管理者；实际重复执行者／行为分母是 T 时每周至少一次在生产环境完成“机器默认执行—人类处理例外—责任人设定边界”闭环的去重组织／责任人，而不是所有被影响劳动者；本卡没有可引用的亿级闭环执行分母，因此亿只能写影响面；主要**提高既有专业者上限**，工作单元改造主体是组织。
- **普及闸复核**：影响面不是同一动作的可引用行为统计，且组织必须完成工作流替换与局部闭环；闸一不过，按组织性判断书写。
- **所以现在可以做什么**: 可立即测量／试点：围绕本卡“领先指标”建立基线或在其限定受众与场景内做小范围试点；不得把测量结果提前写成已验证趋势或超出证据边界的商机。
- **透镜**：技术次序 + 组织载体 + 普及闸二至闸四。
- **推理链**：生成和工具调用先成熟 → 边界清楚、可复核任务先被嵌入 → 例外与责任仍需主体 → 最小生产单元先变成人类责任人监督多次机器执行。
- **时间窗**：2026–2031。
- **证伪条件**：到 2031 年，在至少三个大型知识工作行业，持续十二个月的生产级 AI 部署中，采用“机器默认执行／人类处理例外／责任人设定边界”工作单元的比例仍不足一半；无论另一半由端到端无人执行占据，还是部署普遍停在演示与失败阶段，均触发本卡证伪。
- **领先指标**：默认执行占比、人工接管率、每名责任人监督的执行数、部署前流程重构时数、十二个月留存；每半年。
- **置信度**：中
- **depends-on**：J-006, J-007, J-009, J-066, J-068。
- **最强反方**：端到端可靠性可能跃升，使组织跳过监督单元而直接委托完整结果。
- **与共识**：**一致**：NIST 要求治理、测量、监测与人类监督。**边界**：不证明监督单元是主流组织形态或本卡时间窗。**我为何仍坚持**：既有责任主体和工作流是已存在的载体，逐任务替换比一次性重建企业边界更容易过普及闸。
- **外部对照来源**：EXT-4。
- **出处**：[C7：技术先到，权力后到](../chains/70-capability-to-social-consequences.md)。

### J-088 · 初级产出席位先于职业整体收缩，学徒载体成为新瓶颈
- **历史迁移**：[逐卡历史迁移清单 · J-088](../../evidence/legacy-ledger-migration.md#j-088)；原始卡快照固定于 Git `1f99c832be8cbc82631beb7679d82994a2b7e0fb^`，当前卡不覆盖该快照。

- **提出日期**：2026-09-21
- **一句话判断**：2027–2034 年，在生成密集职业中，初级产出席位和例行工时的相对收缩先于职业总人数下降，受监督实战成为技能形成瓶颈。
- **受众规模**：初级知识工作者、求职者与专业训练者为构造式千万量级；主要**提高既有专业者上限**，但收窄新人的职业入口。
- **普及闸复核**：职业入口是低频制度安排，不是社会成员反复执行的同一动作；闸一不过，按劳动市场与技能形成判断书写。
- **所以现在可以做什么**: 可立即测量／试点：围绕本卡“领先指标”建立基线或在其限定受众与场景内做小范围试点；不得把测量结果提前写成已验证趋势或超出证据边界的商机。
- **透镜**：任务束 + 技能形成 + 信号博弈。
- **推理链**：初级产出最易验证并自动化 → 资深者用更少初级工时维持产量 → 新人失去以真实任务练习的载体 → 学徒、模拟与受监督实战的稀缺上升。
- **时间窗**：2027–2034。
- **证伪条件**：到 2032 年，在至少五个生成密集职业中，初级席位占比没有先于职业总人数下降；或虽先下降，但可验证的学徒、模拟、轮岗或受监督实战容量同步扩张到足以维持采用前的专业者补充率。初级席位与职业总人数同步下降或晚于整体收缩，也触发本卡证伪。
- **领先指标**：初级／资深招聘比、入职任务结构、学徒席位、监督时数、晋升周期、外部候选人的受控表现；每年。
- **置信度**：中
- **depends-on**：J-087, J-083, J-066。
- **最强反方**：AI 辅导与高保真模拟可能同时降低训练成本，使更多新人获得比旧工作更密集的反馈。
- **与共识**：**部分一致**：ILO 2025 的全球职业暴露指数发现全球约四分之一劳动者处于某种 GenAI 暴露中，并判断多数职业更可能被转化而非整岗替代。**边界**：该指数不提供初级招聘、学徒载体、净就业或本卡时间窗。**我为何仍坚持**：被替掉的例行产出同时是旧职业的练习载体，而新载体不会由生成能力自动建立。
- **外部对照来源**：EXT-60。
- **出处**：[C7：技术先到，权力后到](../chains/70-capability-to-social-consequences.md)。

### J-089 · 权限、审计与申诉控制面先于广泛自主授权成为生产基础设施
- **历史迁移**：[逐卡历史迁移清单 · J-089](../../evidence/legacy-ledger-migration.md#j-089)；原始卡快照固定于 Git `1f99c832be8cbc82631beb7679d82994a2b7e0fb^`，当前卡不覆盖该快照。

- **提出日期**：2026-09-21
- **一句话判断**：2026–2032 年，能持续调用工具的 AI 广泛获得高责任自主权之前，身份、权限、日志、暂停、审计与申诉进入核心生产系统。
- **受众规模**：受高责任自动化影响的员工、客户与公民为构造式亿量级；主要**提高既有专业者上限**，控制动作由组织与公共机构执行。

- **所以现在可以做什么**: 可立即测量／试点：围绕本卡“领先指标”建立基线或在其限定受众与场景内做小范围试点；不得把测量结果提前写成已验证趋势或超出证据边界的商机。

- **时间窗**：2026–2032。

- **最强反方**：低事故率和平台级保险可能让组织接受黑箱自治，以事后赔偿替代逐项控制。

- **外部对照来源**：EXT-4, EXT-10。

- **受众规模**：企业、劳动者与消费者为构造式十亿量级影响面；主要**提高既有专业者上限**，收益分配由资产所有者与制度决定。
