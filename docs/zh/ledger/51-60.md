### J-055 · 高责任任务中的现实信号以合同资产形式获得溢价
- **历史迁移**：[逐卡历史迁移清单 · J-055](../../evidence/legacy-ledger-migration.md#j-055)；原始卡快照固定于 Git `1f99c832be8cbc82631beb7679d82994a2b7e0fb^`，当前卡不覆盖该快照。

- **提出日期**：2026-09-18
- **一句话判断**：在高责任任务中，带来源、许可、校准与责任链的现实信号比数据文件本身更可能获得结构性溢价。
- **受众规模**：基于现有普及闸复核重建：千万量级（高责任任务的专业者、采购方与承保方），周频；提高既有专业者上限；历史卡没有独立字段，非独立统计。
- **普及闸复核**：受众规模＝千万量级（高责任任务的专业者、采购方与承保方），周频；闸一**不过**——按普及闸降级为职业／组织性判断，不得以「整个社会」「普遍」「成为风气」的口吻引用。
- **所以现在可以做什么**: 可立即测量／试点：围绕本卡“领先指标”建立基线或在其限定受众与场景内做小范围试点；不得把测量结果提前写成已验证趋势或超出证据边界的商机。
- **透镜**：L1（丰富→稀缺）+ L2（约束迁移）+ L5（信号伪造）+ L6（不可逆性）。
- **推理链**：C1 使二手表达和合成样本丰富 → 普通数据文件的边际价格下降 → 高责任任务仍需要现实观测、来源证明和可追索主体 → 采集许可、校准、使用边界与赔付义务被写入合同 → 数据从文件变成带责任链的合同资产。
- **时间窗**：2029–2033。
- **证伪条件**：到 2033 年，在多个高责任领域，合成证据被监管、保险与买方普遍接受，事故率不高于现实信号，且来源、校准与责任链不再带来可观察溢价。
- **领先指标**：高责任审批中合成证据的占比、带来源与校准条款的数据合同溢价、现实试验预算占比、数据责任保险费率；每半年观察。
- **置信度**：中
- **depends-on**：J-005, J-033, J-034, J-039。
- **最强反方**：高保真世界模型和统一平台赔付可能让现实观测与提供者责任被内部吸收；若平台承担全部错误且买方不再单独支付来源与责任，独立合同资产层不成立。
- **与共识**：与“数据治理、来源和可信度更重要”的方向一致，但本项目把范围收窄到高责任任务；现实信号是否形成独立溢价仍未证实。仍坚持：高责任任务需要现实观测、来源证明与可追索主体，这三者不能由重组生成；独立溢价未被证实，因此置信度保持「中」。
- **外部对照来源**：EXT-7, EXT-10, EXT-14（见上方来源索引）。
- **出处**：[C2：现实信号如何变成合同资产](../chains/20-real-signals-become-contracts.md)。
- **下次检查日**：2027-06-30。

### J-056 · 算力扩张的绑定约束从芯片供给迁移到电力交付与并网许可
- **历史迁移**：[逐卡历史迁移清单 · J-056](../../evidence/legacy-ledger-migration.md#j-056)；原始卡快照固定于 Git `1f99c832be8cbc82631beb7679d82994a2b7e0fb^`，当前卡不覆盖该快照。

- **提出日期**：2026-09-19
- **一句话判断**：算力扩张的绑定约束在本窗口内从芯片供给迁移到电力交付与并网许可。
- **受众规模**：基于现有普及闸复核重建：千万量级（数据中心运营者、电力开发者与许可机构），周频；提高既有专业者上限；历史卡没有独立字段，非独立统计。
- **普及闸复核**：受众规模＝千万量级（数据中心运营者、电力开发者与许可机构），周频；闸一**不过**——按普及闸降级为职业／组织性判断，不得以「整个社会」「普遍」「成为风气」的口吻引用。
- **所以现在可以做什么**: 可立即测量／试点：围绕本卡“领先指标”建立基线或在其限定受众与场景内做小范围试点；不得把测量结果提前写成已验证趋势或超出证据边界的商机。
- **透镜**：L2 约束迁移、L4 扩散滞后。
- **推理链**：芯片是可量产、可运输、可全球再分配的工业品，扩产弹性随投资上升 → 变压器、高压设备与线路受重型制造与施工周期约束，几乎不能靠增加订单提速，且不可跨区域调剂 → 并网、环评与用地许可的周期由行政流程与地方政治决定，与技术进步解耦 → 三条供给曲线的斜率相差一个量级 → 资本集中涌入时，先耗尽的是许可与并网队列，而不是晶圆。
- **时间窗**：2026–2031。
- **证伪条件**：到 2031 年，主要市场新建算力项目的上线延迟中，归因于芯片交付的仍多于归因于电力交付与并网许可的；或主要市场的大负荷接入平均等待时长较 2026 年下降。
- **领先指标**：大负荷接入与并网排队时长、变压器与高压开关设备交货期、项目宣布到通电的平均时长、电力合同签约早于硬件订单的比例；每半年。
- **置信度**：中
- **depends-on**：J-001, J-027。
- **最强反方**：单位服务功耗下降快过服务量增长，或算力投资出现一次显著回撤，使负荷增长始终追不上电网扩容，约束从未真正绑定；若观察到新增负荷增速低于可交付容量增速，本卡动摇。
- **与共识**：与“AI 用电增长构成现实约束”的方向一致；本项目的主张更窄也更可证伪——绑定约束是交付与许可的**时序**，不是发电总量。外部对照本轮只取得发电侧排队证据（EXT-19 明确不覆盖负荷侧），负荷侧排队数据未取得，因此一致性只到机制层。我为何仍坚持：负荷侧统计虽缺，机制的两条腿已分别被佐证——DOE 记录超大规模设施（300–1000MW+）的接入前置期为 1–3 年，并因此转向与现有电厂共址以更快取电（EXT-29）；ERCOT 的大负荷排队积压持续扩大，是唯一公开的负荷侧 ISO 级数据（EXT-30）。置信度维持「中」不上调，因为跨市场的负荷侧排队统计仍不存在。
- **外部对照来源**：EXT-12, EXT-19, EXT-29, EXT-30（见上方来源索引）。
- **出处**：[C3：电子落地](../chains/30-power-land-and-permits.md)。
- **下次检查日**：2027-03-31。

### J-057 · 被定价的不是电量而是可交付时间的确定性
- **历史迁移**：[逐卡历史迁移清单 · J-057](../../evidence/legacy-ledger-migration.md#j-057)；原始卡快照固定于 Git `1f99c832be8cbc82631beb7679d82994a2b7e0fb^`，当前卡不覆盖该快照。

- **提出日期**：2026-09-19
- **一句话判断**：在算力的电力交易中，被定价的主要不是电量，而是“在承诺日期一定通电”的确定性。
- **受众规模**：基于现有普及闸复核重建：千万量级（算力买方、运营方与场址开发者），周频；提高既有专业者上限；历史卡没有独立字段，非独立统计。
- **普及闸复核**：受众规模＝千万量级（算力买方、运营方与场址开发者），周频；闸一**不过**——按普及闸降级为职业／组织性判断，不得以「整个社会」「普遍」「成为风气」的口吻引用。
- **所以现在可以做什么**: 可立即测量／试点：围绕本卡“领先指标”建立基线或在其限定受众与场景内做小范围试点；不得把测量结果提前写成已验证趋势或超出证据边界的商机。
- **透镜**：L8 人性与需求（为确定性付费）、L3 成本结构。
- **推理链**：J-056 使队列成为绑定约束 → 模型代际窗口短，晚十八个月投产的容量在竞争上大幅贬值 → 买方对投产日期的支付意愿高于对平均电价的支付意愿 → 合同结构长出容量预留费、投产日期担保、延迟赔偿与自备发电、储能过桥条款 → 同一地区“带许可、带并网”的场址与裸地形成远超土建成本的价差。
- **时间窗**：2027–2032。
- **证伪条件**：到 2032 年，大型算力电力合同的价格差异主要由每度电价格解释，而与交付日期担保相关的条款（容量预留费、提前期溢价、延迟赔偿）未成为普遍条款。
- **领先指标**：监管备案中最低付费与退出费条款的出现数量、同一地区带许可场址与裸地的成交价差、自备发电与储能作为过桥方案的采用率；每半年。
- **置信度**：中
- **depends-on**：J-056。
- **最强反方**：算力需求出现一次显著回撤使队列消失；或电网普遍提速，使等待时间不再有区分度，确定性不再稀缺。
- **与共识**：**部分一致，但一致点不落在本卡的主张上。** 一致：监管核准的大负荷合同确实围绕「承诺与期限」而非每度电价格分层——FERC 要求 PJM 为共址负荷设立按容量承诺等级区分的三档服务（EXT-21）；PUCO 核准的 AEP Ohio 关税以 85% 最低付费、12 年期、4 年爬坡、退出费与财务担保构成价格保护（EXT-22）。**分歧**：这些条款保护的是**供方**不被弃单套牢，而本卡主张的是**买方**为「按期通电」付溢价；两者都指向「时间与承诺被定价」，但方向相反，不能互相替代。**证据边界**：本卡的证伪条件要求比较合同条款的普遍性，而大负荷合同的商业条款几乎全部保密，公开统计不存在——该证伪条件目前**不可计算**。我为何仍坚持：机制方向获得两个司法辖区的独立支持，判断保留，置信度维持「中」不上调；同时把领先指标的重心从「合同条款比例」移到可公开查证的代理——监管备案中最低付费与退出费条款的出现数量，以及同一地区带许可场址与裸地的成交价差。
- **外部对照来源**：EXT-21, EXT-22（见上方来源索引）。
- **出处**：[C3：电子落地](../chains/30-power-land-and-permits.md)。

### J-058 · AI 负荷分裂为延迟敏感与可调度两类，可调度部分成为电网的灵活性资源
- **历史迁移**：[逐卡历史迁移清单 · J-058](../../evidence/legacy-ledger-migration.md#j-058)；原始卡快照固定于 Git `1f99c832be8cbc82631beb7679d82994a2b7e0fb^`，当前卡不覆盖该快照。

- **提出日期**：2026-09-19
- **一句话判断**：AI 负荷分裂为延迟敏感与可调度两类，可调度的那部分成为电网可付费购买的灵活性资源，而不只是负担。
- **受众规模**：基于现有普及闸复核重建：千万量级（电网、数据中心与能源交易参与者），周频；提高既有专业者上限；历史卡没有独立字段，非独立统计。

- **透镜**：L2 约束迁移、L3 成本结构。
- **推理链**：交互式推理延迟敏感、不可中断、不可迁移 → 训练、批量推理与评估可暂停、可延后、可跨时区迁移 → 后者的中断成本主要是时间而非报废，与电解铝等传统重工业负荷性质不同 → 电网最缺的是灵活性，且需求响应、可中断电价与容量市场是现成的付费通道 → 可调度算力同时是负荷与资源，其真实电力成本可低于名义电价。
- **时间窗**：2027–2033。
- **证伪条件**：到 2033 年，主要市场数据中心在可中断／需求响应合同中的签约容量仍可忽略（不足其签约容量的 5%），且大型算力用户普遍拒绝可中断条款。

### J-059 · 算力管制的抓手从硬件出口转向使用侧
- **历史迁移**：[逐卡历史迁移清单 · J-059](../../evidence/legacy-ledger-migration.md#j-059)；原始卡快照固定于 Git `1f99c832be8cbc82631beb7679d82994a2b7e0fb^`，当前卡不覆盖该快照。
