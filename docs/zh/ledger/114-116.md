# 判断卡片 J-112–J-113

[English version](../../en/ledger/114-116.md)

本分片登记 C16「文化、环境与日常承载」的两张完整卡。

### J-112 · 闲暇文化消费受时间预算与可达性约束

- **提出日期**：2026-10-17
- **一句话判断**：2027–2032 年，在有可比数据的高收入城市，中等收入成年人线下文化参与会继续受碎片化闲暇、票价与到达时间约束，而可暂停的流媒体／短视频会替代部分日常娱乐时段；这只是方向判断，不指定平台或国家赢家。
- **受众规模**：受影响人口＝高收入城市中等收入成年人及文化场馆、家庭，亿量级影响面；实际重复执行者／行为分母＝在 T 时每月至少一次购买或参加文化娱乐活动的去重成年人，当前没有跨国统一分母，不能声称亿级普及；能力类型＝不适用，不提高既有专业者上限，也不让原本不会者也能做。
- **普及闸复核**：闸一不过；本卡判断文化参与约束而非技术扩散。
- **透镜**：人性与需求、供需关系、社会规律、地理约束；技术仅是媒介形态，不是起点。
- **推理链**：工作与照护切碎闲暇 → 票价、距离和排队放大线下参与的固定成本 → 可暂停媒介降低协调成本并占据零碎时段 → 线下文化仍由身份、社交和场所体验支撑 → 结果更可能是时段替代与分层，而非一种媒介全面取代文化。
- **时间窗**：2027-01-01 至 2032-12-31
- **证伪条件**：在预注册的至少 12 个高收入城市中，若相对 2024–2026 基线，线下文化参与频率在中等收入成年人中位数连续三年上升至少 10%，且时间使用显示碎片化下降、票价负担不升、流媒体娱乐时长不增加，则“约束与部分替代”方向被证伪；缺失统一时间使用数据时记为不可判定。
- **领先指标**：时间使用调查、文化票价／收入比、场馆到达时间、月度重复参与率与流媒体时长；每年。
- **置信度**：中
- **depends-on**：J-109, J-111
- **最强反方**：四日工作制、公共托育与低价文化补贴同时扩张，可能释放连续闲暇并使线下参与普遍回升；流媒体也可能刺激而非替代现场参与。
- **与共识**：一致：时间、价格与可达性影响文化参与。分歧：不把流媒体增长写成线下文化必然衰退；数据不足处保持仅图景。仍坚持，因为时间预算和固定成本可被城市面板检验。
- **外部对照来源**：EXT-120
- **出处**：[C16 第一节](../chains/160-culture-climate-mobility.md)
- **下次检查日**：2028-12-31
- **状态**：ACTIVE

### J-113 · 气候冲击先通过保险、适应与出行中断扩大不平等

- **提出日期**：2026-10-17
- **一句话判断**：2027–2035 年，高气候暴露地区的家庭与地方政府更可能先通过保险缺口、适应投资不足和出行中断承受环境冲击，低收入家庭与财政薄弱地区的可支配消费和居住稳定性风险更高；具体灾害与规模仍不是确定预测。
- **受众规模**：受影响人口＝高暴露地区居民、通勤者、地方政府与保险持有人，十亿量级影响面；实际重复执行者／行为分母＝不适用，本卡判断制度风险传导而非重复动作；能力类型＝不适用，不提高既有专业者上限，也不让原本不会的人也能做。
- **普及闸复核**：闸一不过；本卡判断制度风险传导而非技术扩散。
- **透镜**：环境约束、供需关系、资本与制度、地理、社会规律；以非 AI 的物理暴露和财政能力为起点。
- **推理链**：极端天气与基础设施脆弱性造成损失 → 保费、免赔额和停运上升 → 低收入家庭缺乏适应资本且更难搬迁 → 地方财政需在修复、公共安全与长期适应间分配 → 风险通过食品、住房、收入和迁移扩大不平等；及时适应可缓冲，故不是单向必然。
- **时间窗**：2027-01-01 至 2035-12-31
- **证伪条件**：在预注册的至少 20 个高暴露地区，若连续五年灾害相关保费／免赔额、道路或公共交通中断天数均不高于 2024–2026 基线，且低收入家庭住房负担与非必要消费损失相对高收入组不扩大，同时适应投资达到登记目标，则“风险先扩大不平等”的方向被证伪；没有可比分组或损失数据时不可判定。
- **领先指标**：极端天气损失、保险拒保／保费、停电与道路中断、地方适应资本支出、食品价格、迁移与住房负担；季度／年度。
- **置信度**：中
- **depends-on**：J-061, J-095, J-109
- **最强反方**：保险共同池、中央财政转移和提前适应投资可能把暴露转化为可承受成本；高收入家庭也可能因资产集中承担更大绝对损失。
- **与共识**：一致：气候损失、保险与适应能力分布不均。分歧：不把每次灾害或迁移写成确定结果；只判断可观察的传导机制，地区差异仍开放。
- **外部对照来源**：EXT-121
- **出处**：[C16 第二节](../chains/160-culture-climate-mobility.md)
- **下次检查日**：2029-12-31
- **状态**：ACTIVE
