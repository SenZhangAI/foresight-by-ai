# 判断卡片 J-096–J-102

[English version](../../en/ledger/96-102.md)

### J-096 · 老龄化与家庭缩小把部分照护推向正式服务与协调层

- **提出日期**：2026-09-28
- **一句话判断**：2027–2035 年，老龄化与家庭缩小会使部分照护从家庭内部的隐性义务转向正式服务、保险／公共支付和跨机构协调；但这不等于家庭亲手照护退出。
- **受众规模**：受影响人群为照护对象、家庭成员和照护劳动者，构造式千万量级影响面；实际重复执行者是每周至少一次完成亲手照护或照护协调的成年人，现有可比证据只支持百万量级以内的职业／调查子群，不能据此声称亿级普及。主要是提高既有专业者上限并重新分配既有照护者的负担，也让原本无法持续照护的家庭使用正式服务。
- **普及闸复核**：闸一（规模）不过：当前没有全球去重的周频行动者分母，按制度／职业性判断；闸二（替代）部分通过：正式服务替代家庭的一部分连续照护时间，但没有替掉照护总需求；闸三（承载）部分通过：保险、公共服务和现有照护机构提供承载物，质量与覆盖不齐；闸四（决策）部分通过：支付方、机构和家庭必须共同改变，制度授权或局部闭环尚未统一；闸五（持续净负担）待核验：正式服务相对家庭照护的长期净负担与可负担性尚无跨制度序列。未解锁闸不支持社会级普及，只支持制度与职业层判断；提高既有专业者上限。
- **所以现在可以做什么**：优先测量照护协调、排班、异常升级、授权记录和服务可追踪性；不要把全球家庭机器人或亿级个人周频动作作为产品前提。
- **透镜**：人口结构（**L1–L9 中无承载透镜**，见 §2.1「不采用 L1 的示例」）、供需与支付（**L1**、**L3**）、制度替代（**只被部分承载**：「由家庭、市场还是公共制度承担」这一面是 make-or-buy 边界，由 **L3** 承重（2026-10-10 补记：L3 定义列举的用途止于「公司规模、雇佣关系、外包边界和产品打包方式」，用到家庭层属外推；这一问法本身的逐字出处在 §2.1「再检查照护责任由家庭、市场还是公共制度承担」）；但「制度替代既有承担者」本身在 L1–L9 里没有源句，L7 也只承接「制度后到」这一端）、家庭关系（**L8**）（代号定义见[方法论 §2](../00-method.md#2-透镜工具箱)，缺口见[映射表](../00-method.md#五类起点与-l1l9-的对应表)）。
- **推理链**：老年照护需求持续 → 可用家庭时间相对减少 → 无偿照护出现排班、请假和连续性缺口 → 保险／公共服务与协调岗位承接部分动作 → 家庭仍保留授权、陪伴和异常决策。
- **时间窗**：2027–2035。
- **证伪条件**：到 2033 年，在至少四个具有可比人口与照护统计的制度中，家庭照护时间、正式照护支出和协调岗位均没有向正式／协调载体移动；或者移动完全由短期经济周期解释，而非人口结构与家庭规模变化。
- **领先指标**：非正式照护者的日／周频率、照护请假与退出劳动市场比例、长期护理保险／公共照护支出、居家服务工时、照护协调岗位与等待时间；每年。
- **置信度**：中
- **depends-on**：J-066, J-073。
- **最强反方**：生产率和移民供给提高了家庭可购买的照护服务，或延迟失能使需求增长低于人口结构推断，导致家庭与正式载体的分工不明显。
- **与共识**：**部分一致**：OECD 的可比调查证明日频／周频非正式照护真实存在，日本与瑞典证明制度可以重组照护载体。**边界**：这些材料不能给出全球照护者分母，也不能证明正式服务会在所有制度扩张。**我仍保留**：家庭时间是不可储存的约束，制度选择会改变谁执行动作，但不会消除连续照护本身。
- **外部对照来源**：EXT-62, EXT-63, EXT-64。
- **出处**：[C9：人口老龄化与制度化照护](../chains/90-aging-care-and-institutional-substitution.md)。
- **下次检查日**：2027-06-30。
- **隔离盲判复审（2026-10-09）**：盲判编号 R-37，裁定 `ABSTAIN`，无闸位被判否；处置「保留·盲判未否决（闸只能判否，不得据此上调）」。判据、缺证原文与边界见[隔离盲判复审](../../evidence/blind-review-reaudit-2026-10-09.md)。
- **状态**：ACTIVE

### J-097 · 照护辅助先在机构与受控服务中稳定，开放家庭通用机器人滞后

- **提出日期**：2026-09-28
- **一句话判断**：2027–2038 年，接触式转移、异常观察和标准化照护辅助更可能先在机构与受控居家服务中形成稳定流程；开放式家庭环境中的通用照护机器人在此窗口内不构成社会级普及。
- **受众规模**：直接执行者为百万量级以内的护理机构、护理劳动者、设备维护与支付方，主要提高既有专业者上限；被照护者和家庭为千万量级影响面，但不是同一高频技术操作的行动分母。
- **普及闸复核**：闸一（规模）不过：机构采购与家庭部署是低频组织决策，开放式家庭任务没有去重周频行动者分母，按职业／制度性判断；闸二（替代）部分通过：单任务设备可替代部分转移或观察步骤，但不替代照护关系与全部异常处理；闸三（承载）机构先通过、家庭未解锁：机构有采购、培训、维护和记录载体，异构家庭没有统一承载物；闸四（决策）机构局部通过、家庭未解锁：机构可集中决定，家庭涉及亲属、服务商、支付方与责任人；闸五（持续净负担）待核验：事故、维护、改造和人工接管成本尚无可比序列。未解锁闸不支持社会级普及；提高既有专业者上限，不让原本不会的人普遍获得新动作。
- **所以现在可以做什么**：先在机构或受控居家服务验证单任务设备的留存、人工接管、事故与维护成本；把远程观察、提醒、排班和异常升级作为家庭入口，不把通用家庭机器人当作社会级市场前提。
- **透镜**：任务可分解性（**L1–L9 中无承载透镜**，属映射表「技术规律」行「哪类工作先降本」的缺口）、机构经济学（**L3**）、物理与责任约束（**L6**）、普及闸（**不是透镜**，见 §2「普及闸不是第十种可选透镜」）（代号定义见[方法论 §2](../00-method.md#2-透镜工具箱)，缺口见[映射表](../00-method.md#五类起点与-l1l9-的对应表)）。
- **推理链**：可重复任务更容易标准化 → 机构集中采购和培训降低单位部署成本 → 责任、维护和记录可以绑定组织 → 受控场景先稳定 → 家庭的异构空间、低频突发与责任外溢阻慢通用设备扩散。
- **时间窗**：2027–2038。
- **证伪条件**：到 2035 年，在多个收入层级和至少三个制度环境中，开放式家庭照护机器人已被大量家庭持续使用，且能够覆盖至少三类跨空间任务（如转移、清洁、异常处理），其留存率、事故率和维护成本不再显著劣于机构部署；若只有展示、试点或单任务设备，不算推翻。
- **领先指标**：机构设备的付费部署与留存、每千名被照护者的设备工时、家庭设备的持续使用月数、跨任务成功率、事故与人工接管率、维护／改造成本；每年。
- **置信度**：中
- **depends-on**：J-073, J-074, J-066, J-069。
- **最强反方**：低成本软硬件、住宅改造和保险支付同时成熟，把家庭变成可标准化的受控环境；或照护劳动力短缺迫使制度承担高额补贴，跳过自然扩散速度。
- **与共识**：**部分一致**：具身智能在工厂等重复场景的扩散，以及接触式转移原型，支持「能力能做、机构更易承接」的方向。**边界**：现有来源没有跨国部署量、留存率和家庭事故数据，不能把机构先行写成已验证事实。**我仍保留**：家庭开放环境同时叠加物理不确定性、责任外溢和维护成本，按照历史扩散规律应先于能力曲线构成瓶颈。
- **外部对照来源**：EXT-43, EXT-44, EXT-45。
- **出处**：[C9：人口老龄化与制度化照护](../chains/90-aging-care-and-institutional-substitution.md)。
- **下次检查日**：2027-12-31。
- **隔离盲判复审（2026-10-09）**：盲判编号 R-25，裁定 `ABSTAIN`，无闸位被判否；处置「保留·盲判未否决（闸只能判否，不得据此上调）」。判据、缺证原文与边界见[隔离盲判复审](../../evidence/blind-review-reaudit-2026-10-09.md)。
- **状态**：ACTIVE

### J-098 · 授权先于智能：高责任场景先形成可撤回的分级代理

- **提出日期**：2026-10-01
- **一句话判断**：2027–2035 年，高责任场景中的人与 AI 关系更可能先稳定为挂靠在个人、组织或公共机构责任之下的分级代理；授权、撤回、日志和申诉会先成为可见接口，而不是出现被广泛承认为独立责任主体的 AI。
- **受众规模**：直接行动者是百万量级以内的高责任岗位、合规／安全人员、服务提供者和公共机构；受影响的客户、劳动者与居民为千万量级影响面。它提高既有专业者上限与组织的执行能力，不让原本没有责任资格的人普遍获得不可逆的决策权。必要频次边界仍未验证：当前没有跨制度去重的每周行动者分母，因此百万量级只是职业／制度层上限，不是社会级周频人数。
- **普及闸复核**：闸一不过：授权与责任是低频组织／职业动作，不存在同一社会级周频行动者分母；闸二部分通过：AI 可替代部分记录、匹配和执行步骤，但不替代授权与责任承担；闸三通过于已有组织、未通过于无承载物的个人关系；闸四部分通过：法律与合同可以局部闭环，跨主体撤回和申诉仍未统一；闸五待核验：事故、保险、培训和审计的持续净负担缺少跨行业序列。因此这是制度／职业性判断，不是 AI 获得主体性的社会级预测。
- **所以现在可以做什么**：把授权范围、可撤回条件、越权告警、操作日志、人工接管、申诉和损失承接写成产品或采购的先验字段；先在一个已有责任主体的窄流程里测量，而不是从「AI 员工」或「AI 朋友」的主体性叙事起步。
- **透镜**：代理制度（**L1–L9 中无承载透镜**，属映射表「社会规律」行登记的条文空缺：决定权归属与多方协同无源句）、法律责任（**L6**）、组织协作（**L3**）、权力与关系边界（**L7**、**L9**）（代号定义见[方法论 §2](../00-method.md#2-透镜工具箱)，缺口见[映射表](../00-method.md#五类起点与-l1l9-的对应表)）。
- **推理链**：社会需要持续委托 → 制度把授权、撤回、监督、证据和责任拆开 → 已有责任主体先承接数字代理 → AI 在受控边界内扩大执行范围 → 人与 AI 的关系先成为权限与责任关系。
- **时间窗**：2027–2035。
- **证伪条件**：到 2033 年，在至少三个高责任制度环境中，大量持续使用的 AI 代理已经能够脱离个人、组织或公共机构的责任承接，且不需要可追踪授权、撤回、日志、申诉和赔付安排；或者这些接口普遍存在，却没有改变采购、事故处置和代理权限的实际边界。一次性演示、无责任聊天和试点不算推翻。
- **领先指标**：高责任 AI 合同中授权／撤回／越权条款的比例；有人工接管和申诉路径的持续部署数；代理事故的责任归属与保险除外条款；跨主体撤回的完成时间；按季度或年度观察。
- **置信度**：中
- **depends-on**：J-009, J-031, J-055, J-065, J-070。
- **最强反方**：平台可能把责任、保险和审计统一内置并免费提供，使独立的授权基础设施不形成稳定供给；或者某些制度允许低风险代理先取得事实上的自主地位，再倒逼法律追认。
- **与共识**：**部分一致**：现有治理框架普遍强调人类监督、日志和问责。**边界**：这些材料不证明分级代理会在所有行业按同一顺序扩散，也不证明 AI 永远不会获得某种有限法律地位。**我仍保留**：代理的社会承载物先于代理工具存在，责任和撤回是不可由语言流畅度替代的制度接口。
- **外部对照来源**：EXT-10, EXT-14, EXT-15。
- **出处**：[C11：授权先于智能](../chains/110-authority-before-intelligence.md)。
- **下次检查日**：2027-06-30。
- **隔离盲判复审（2026-10-09）**：盲判编号 R-22，裁定 `ABSTAIN`，无闸位被判否；处置「保留·盲判未否决（闸只能判否，不得据此上调）」。判据、缺证原文与边界见[隔离盲判复审](../../evidence/blind-review-reaudit-2026-10-09.md)。
- **状态**：ACTIVE

### J-099 · 具身自动化先重排职业任务包而非同步消灭整个职业

- **提出日期**：2026-10-01
- **一句话判断**：2027–2035 年，具身系统更可能先替掉仓储、制造、农业与照护职业中重复且可接管的任务段，再重排异常处理、关系维护与责任签字；它不会仅凭能力曲线同步消灭整个职业。
- **受众规模**：受影响人群为上述行业劳动者与服务接受者，构造式千万量级影响面；实际重复执行者是采用密集地区中每周执行被测任务段的劳动者，当前只能从职业与设备部署口径构造百万量级以内分母，不能声称社会级普及。提高既有专业者上限；具体而言，提高既有专业者在异常与责任任务上的上限，也把部分结构化动作交给原本不做该动作的设备系统。
- **普及闸复核**：闸一不过：跨行业任务段没有统一去重行动者分母，按职业／组织性判断；闸二部分通过：设备替代具体动作但不替代整项服务；闸三由场景决定；闸四需要雇主、保险、工会和监管局部闭环；闸五待核验：接管、停机和培训的持续净负担缺少序列。未解锁闸不支持净就业或社会级普及断言。
- **所以现在可以做什么**：按任务包记录自动化频次、人工接管时长、异常处理工资、设备所有权与停机风险，不按“职业是否被替代”一个指标做培训或裁员决策。
- **透镜**：任务分解（**只被部分承载**，2026-10-10 经独立攻击改判，原写「L1–L9 中无承载透镜」：本卡「再重排异常处理、关系维护与责任签字」与「不会仅凭能力曲线同步消灭整个职业」这一面是瓶颈换位，由 **L2**「解除一个瓶颈不会让系统所有环节均匀变快，瓶颈会跳到另一个环节」承载，L2 定义也写明「它用于寻找新岗位」；无承载的只剩另一面——「哪一类任务段**先**被替掉」，与 J-097 是同一处技术规律缺口）、历史扩散（**L4**）、供需（**L1**）、劳动制度与责任约束（**L7**、**L6**）（代号定义见[方法论 §2](../00-method.md#2-透镜工具箱)，缺口见[映射表](../00-method.md#五类起点与-l1l9-的对应表)）。
- **推理链**：结构化且失败可接管的动作先过单位成本 → 职业内部任务包被拆分 → 人工时间转向异常、关系和责任 → 岗位数量同时受需求扩张、价格变化和组织选择影响 → 净就业方向不能从机器人能力单独推出。
- **时间窗**：2027–2035。
- **证伪条件**：到 2033 年，在至少三个上述行业、三个制度环境中，具身采用密集地区的职业总量与任务结构均未出现可重复的任务重排，且设备始终只增加而不替代任何可定义动作；或出现跨行业、可比的整职业净减少，并能排除需求、价格和制度变化的解释。
- **领先指标**：按任务段而非职业记录的机器人作业小时、人工接管分钟、异常处理工资、停机损失、培训时长与岗位总量；每年。
- **置信度**：中
- **depends-on**：J-073, J-075, J-076, J-077, J-078, J-091。
- **最强反方**：通用设备、低成本租赁和平台化责任承接可能让整项服务被一体化替代，任务重排阶段极短；或者需求没有扩张，多个任务段同时消失。
