### J-041 · AI 先扩大弱关系的协调半径
- **历史迁移**：[逐卡历史迁移清单 · J-041](../../evidence/legacy-ledger-migration.md#j-041)；原始卡快照固定于 Git `1f99c832be8cbc82631beb7679d82994a2b7e0fb^`，当前卡不覆盖该快照。

- **提出日期**：2026-09-18
- **一句话判断**：AI 先扩大弱关系的协调半径
- **受众规模**：基于现有普及闸复核重建：亿量级（数字沟通者与组织协调者），周频；提高既有专业者上限；历史卡没有独立字段，非独立统计。
- **普及闸复核**：受众规模＝亿量级（数字沟通者与组织协调者），周频；闸一**不过**——按普及闸降级为职业／组织性判断，不得以「整个社会」「普遍」「成为风气」的口吻引用。 **判定口径**：这里的亿量级只是构造式推算的受众上限（按职业、组织节点或需求人群估计），不是可引用的统计，也没有证明存在「亿级不同个人每周执行同一动作」的社会级重复行为，因此闸一仍判不过。 本卡的受众被写成可能用户、平台参与者或受影响人群，**影响面估计不等于重复执行人数**，不得据此上调闸一判定。
- **所以现在可以做什么**: 行动：在多家合作单位之间约会议、做引荐、对接资料的项目协调员——两周内从自己的邮箱和日历里取最近 30 次跨组织协调，逐条标三项：是否用了 AI 做翻译、引荐稿或约时；对方是首次或低频联系人（弱关系），还是长期共担项目后果的伙伴（强关系）；自己实际花了多少分钟。看什么：若用了 AI 的条目单次人时明显更短、新增联系多落在弱关系一侧，而强关系条目无论用不用 AI 耗时都差不多，你这 30 次协调与判断相符；若两组在人时和联系数上都看不出差别，则指向证伪条件（对应领先指标）。
- **透镜**：L8（人性常数）+ L9（关系不对称）
- **推理链**：沟通与背景同步成本下降 → 翻译、介绍、约时可规模化 → 弱关系连接半径扩大 → 强关系仍受共同承担约束
- **依赖动摇**：若 J-017 被证伪，协调供给前提消失，本卡动摇
- **时间窗**：2027–2033
- **证伪条件**：到 2033 年 AI 中介不提高跨组织弱关系连接数量或降低协调时间
- **领先指标**：AI 中介协调比例、跨组织联系数、单次协调人时；年度观察
- **置信度**：中
- **depends-on**：J-017
- **最强反方**：若 J-017 被证伪，协调供给前提消失，本卡动摇
- **与共识**：方向一致但证据不足：AI 扩大沟通与协调范围，尚无足够数据区分弱关系与强关系的因果变化。仍坚持：协调成本下降先扩大弱关系半径，强关系仍受共同承担约束；因果区分缺口由弱／强关系分项领先指标承担。

### J-042 · 共同经历与身体在场仍是强关系容量上限（仅图景）
- **历史迁移**：[逐卡历史迁移清单 · J-042](../../evidence/legacy-ledger-migration.md#j-042)；原始卡快照固定于 Git `1f99c832be8cbc82631beb7679d82994a2b7e0fb^`，当前卡不覆盖该快照。

- **提出日期**：2026-09-18
- **一句话判断**：共同经历与身体在场仍是强关系容量上限（仅图景）
- **受众规模**：基于现有普及闸复核重建：十亿量级（所有需要共同经历与身体在场的人），日／周频；提高既有专业者上限；历史卡没有独立字段，非独立统计。
- **普及闸复核**：受众规模＝十亿量级（所有需要共同经历与身体在场的人），日／周频；闸一**过**——可作社会级判断书写。
- **所以现在可以做什么**：仅图景：强关系是否受在场约束，要在多年的长期关系里才看得出，任何人两周内对自己几段关系做记录，都分不清是被代理互动替代还是自然疏远。缺什么：同一批长期关系（伴侣、家人、密友）的多年追踪数据，并排记下代理互动时长与共同在场活动时长，再配上冲突后能否修复、关系是否存续的行为结果和当事人自述，两类证据缺一不可。谁能先补：已在做家庭或伴侣纵向追踪的研究团队——在下一轮问卷里把「经 AI 代理或陪伴工具的互动」与「共同在场活动」拆成两道题。
- **透镜**：L2（约束迁移）+ L8（人性常数）+ L9（关系不对称）
- **推理链**：多模态表达变丰富 → 代理陪伴与提醒普及 → 共同经历仍要求身体、时间和互惠后果 → 强关系容量受在场约束

- **证伪条件**：到 2033 年代理互动在长期关系中稳定替代共同经历，且报告与行为结果无差异
- **领先指标**：代理互动与共同活动比例、冲突修复、关系留存；年度观察
- **置信度**：低
- **为何停在仅图景**：缺历史对照组——本卡依靠[方法论 L8](../00-method.md#l8--人性与需求) 的子规律「人能维持的强关系数量不随通信成本下降而扩大」，但本仓库从未按「至少 2 个成功案例＋2 个失败案例」校准过这条子规律：电话、视频通话、社交网络这几次通信成本下降是否替代过强关系的在场，没有一组判否过任何案例的对照；缺领先指标的数据源——证伪条件要求在同一批长期关系里并排记下「经代理的互动时长」与「共同在场时长」，再配冲突修复与关系存续的结果，目前没有任何公开序列这样拆分。两项补齐之前，本卡「普及闸复核」字段里的闸一结论只说明规模轴达十亿量级，不构成以社会级口吻书写的许可（该字段措辞与此冲突，已登记在[社会级判断登记页第五节](../91-social-scale-register.md#五本页不改判这些矛盾已登记待裁)）。
- **depends-on**：J-011
- **最强反方**：若 J-011 被证伪，多模态表达扩张前提减弱；若代理关系稳定替代在场，本卡动摇
- **与共识**：证据不足：伦理与照护治理保留人的主体性，但不能替代强关系容量与替代效应研究。仍坚持：仅作为图景保留，置信度不上调；升级需要长期关系中替代效应的行为与自述双重证据。
- **外部对照来源**：EXT-9（见上方来源索引）。

### J-043 · 高价值代理执行可能转向边界授权，而非逐步操作（仅图景）
- **历史迁移**：[逐卡历史迁移清单 · J-043](../../evidence/legacy-ledger-migration.md#j-043)；原始卡快照固定于 Git `1f99c832be8cbc82631beb7679d82994a2b7e0fb^`，当前卡不覆盖该快照。

- **提出日期**：2026-09-18
- **一句话判断**：高价值代理执行可能转向边界授权，而非逐步操作（仅图景）。
- **受众规模**：基于现有普及闸复核重建：千万量级（高价值代理的组织买方与运营者），周频；提高既有专业者上限；历史卡没有独立字段，非独立统计。

- **所以现在可以做什么**: 仅图景：边界授权以可回滚环境压低监督成本为前提，这个前提尚未在高价值部署里兑现，事故责任或监管也可能继续要求逐步审批，运营方现在改审批流程等于押注一个未成立的前提。缺什么：一批真实的高价值代理部署合同，按「预先划定权限、金额与回滚范围，越界才升级」和「逐步审批」两类编码后的占比，以及回滚是否真的减少了人工监督时数的记录。谁能先补：审查企业软件采购合同的律师或采购联盟——把已签代理部署合同里的授权条款按这两类编码并公布占比。
- **透镜**：L2 约束迁移、L6 不可逆性。
- **推理链**：可回滚环境降低监督成本 → 代理承担更多步骤 → 监督转向权限边界与异常升级 → 高价值部署采用边界授权。

- **最强反方**：事故责任或监管要求逐步审批。
- **与共识**：证据不足的景观：现行治理支持权限边界设计，但不能外推从逐步操作转为边界授权的长期界面。仍坚持：仅作为图景保留，置信度不上调；升级需要边界授权合同占比等实际采用证据，而不是现行权限设计本身。

### J-044 · 可吸收事故的责任位置成为代理基础设施的承重墙（仅图景）

### J-050 · 人类协作的价值从共同做步骤转向共同选择承诺（仅图景）

- **推理链**：代理吸收协调 → 人类介入减少 → 介入集中于不可逆选择与共同担责 → 以承诺质量衡量协作。
