# J-120–J-121 · C20 边界先于能力

[English version](../../en/ledger/120-121.md)

### J-120 · 数据与模型产出的权利会先分层，责任仍挂在可追偿的组织上

- **编号**：J-120
- **提出日期**：2026-10-22
- **一句话判断**：2027–2035 年，数据访问、训练来源、模型产出许可与代理事故责任更可能形成分层、可撤回、按场景分配的权利组合，而不是形成一个统一的“数据所有权”或独立的 AI 责任主体；高责任场景的赔偿与纠错仍优先挂在可追偿的组织、保险与合同网络上。
- **受众规模**：受影响人口＝十亿量级数据主体、消费者与被自动化决策波及的人（影响面，不能据此声称十亿量级实际重复行动）；实际重复执行者／行为分母＝每周至少一次代表机构配置数据权限、模型输出许可或代理责任流程的组织工作人员，当前无跨制度去重分母，`UNKNOWN`；提高既有专业者上限，不让原本不会的人也能做新的责任处理动作。
- **普及闸复核**：受影响人口为十亿级影响面；实际重复执行者分母 `UNKNOWN`，因此不主张社会级普及；提高既有专业者上限；闸一不过。
- **透镜**：L1 供需关系、L4 历史规律、L5 社会规律、L7 制度与权力规律、L8 人性规律；「丰富→稀缺」仅用于检查可复制产出是否把责任和可追偿性变成新约束。
- **推理链**：数据与模型产出可复制但来源、隐私、训练贡献和现实后果不可完全复制 → 访问、使用、收益、撤回和举证被拆成不同权利 → 高责任场景需要可追偿组织、保险、审计和人工复核 → 跨制度代理事故暴露管辖与赔偿冲突 → 制度先扩展分层许可与责任承载，而不是授予模型独立主体资格。
- **时间窗**：2027-01-01 至 2035-12-31
- **证伪条件**：到 2035-12-31，在至少三个制度差异显著的法域中，绝大多数高责任模型事故都由统一的模型供应商／模型主体责任规则直接裁判，且赔偿与纠错不再主要依赖部署组织、合同、保险或人工责任承载；只有当每个法域公开报告覆盖率达到 80% 且无法判定项不超过 20% 时，才把该结果判为证伪，否则维持 `unverified`。高责任事故的纳入条件固定为：模型输出或动作直接或实质性建议影响身体安全、医疗、就业、信贷／福利、法律权利或财产转移，并在 90 日内产生实际损害或正式索赔；同一法域、同一部署、同一主张、时间相差不超过 24 小时的记录以案件 ID 合并，缺少案件 ID 时须至少匹配部署组织、日期、领域和主张四项才合并。覆盖率用公开报告、强制监管／保险记录与独立抽样三类来源，按固定的三源主效应 log-linear 捕获—再捕获模型估计；三源不能建立可链接重叠或模型不收敛时不得宣称达到 80%。若该结果不是由样本定义或报告缺失造成，则本判断被证伪。
- **领先指标**：每半年在预先固定的至少三个制度差异显著法域登记符合上述纳入条件的高责任模型事故母集合（包括境内与跨境部署；固定同一任务类型和时间窗）。三类来源用案件 ID 或四项匹配键链接，按固定的三源主效应 log-linear 捕获—再捕获模型估计母集合；模型不收敛或无法建立重叠时维持 `unverified`。对每起事故记录责任裁判规则、赔偿与纠错是否仍依赖部署组织／合同／保险／人工责任承载和无法判定项；仅当四个连续半年期的每个法域覆盖率均达到 80%、无法判定项不超过 20%，且 `R = 直接由统一模型规则裁判且不依赖上述承载的事故数 / 可判定事故总数` 在三个法域均 `R > 0.5` 时，才报告与证伪条件相同的反向信号。
- **置信度**：中
- **depends-on**：J-055, J-098
- **最强反方**：若统一的模型供应商责任、强制保险或国际互认规则快速出现，责任可能集中到模型提供者或新型主体，而非继续挂在部署组织网络上。
- **与共识**：本轮未完成外部对照；独立推演与“高责任 AI 需要问责、审计和人类监督”的一般治理共识一致，但不接受把治理原则写成分层权利已在全球普遍落地，也不接受把独立 AI 主体资格写成近期必然结果；坚持保留跨法域事故分母缺口。
- **外部对照来源**：未完成对照；待登记各法域数据权利、模型许可、保险与代理事故判例的可比来源。
- **外部对照状态**：INCOMPLETE_NOT_ATTEMPTED；来源集合：NONE。缺口：尚未完成跨法域规则与事故样本的可比登记；下一步：登记至少三个制度差异显著法域的规则、判例与保险条款，再更新状态。
- **出处**：[C20 边界先于能力](../chains/200-law-property-liability-and-geopolitics.md#3-推演链能力扩张先制造边界争议制度以分层许可和责任承载回应)
- **下次检查日**：2029-12-31
- **状态**：ACTIVE

### J-121 · 跨境制度先按关键依赖分区，全球规则不会自动收敛

- **编号**：J-121
- **提出日期**：2026-10-22
- **一句话判断**：2027–2035 年，国家与大型组织更可能先通过许可、出口管制、采购、标准、本地化与互认协议来重写数据、算力和关键基础设施的跨境可用边界，形成多个互操作程度不同的制度区，而不是自动收敛为一套全球统一规则；这不是对战争或某国必胜的预测。
- **受众规模**：受影响人口＝十亿量级居民与跨境服务使用者（被数据流、基础设施依赖和制度区差异波及的影响面）；实际重复执行者／行为分母＝每月代表国家、平台或关键基础设施组织执行跨境许可、采购、标准或供应切换的工作人员与机构，当前无跨国去重分母，`UNKNOWN`；提高既有专业者上限，不让原本不会的人也能做国家级跨境协调。
- **普及闸复核**：受影响人口为十亿级影响面；实际重复执行者分母 `UNKNOWN`，不主张亿级或十亿级实际执行；提高既有专业者上限；闸一不过。
- **透镜**：L1 供需关系、L4 历史规律、L5 社会规律、L7 制度与权力规律、L8 人性规律；不把 C14 的安全预算与选举响应外推为战争、核威慑或全球极化。
- **推理链**：关键基础设施与数据、算力存在地理依赖和替代成本 → 国家与大型组织获得可施加条件的议价筹码 → 跨境冲突先进入许可、采购、标准、出口和本地化程序 → 互认协议降低部分摩擦但保留制度差异 → 企业和居民面对的是分区可用能力与切换成本，而非一套自动统一的全球规则。
- **时间窗**：2027-01-01 至 2035-12-31
- **证伪条件**：预先固定至少三个制度差异显著法域和同一组跨境交易：跨境数据传输、算力服务、关键基础设施服务各至少一种；每种交易须有同一服务规格、提供者—客户对、跨境路线和每年 12 个月观测，排除测试、演示和一次性交易。到 2035-12-31，若这些交易中每个法域的可执行许可、责任、数据流与争议裁决规则的规范化内容（适用范围、许可／义务／限制、执行程序、救济结果）完全相同，且连续两年成功服务可用率的法域间差异不超过 5 个百分点、切换直接货币成本中位数比值不超过 1.2、切换中位耗时比值不超过 1.2，则本判断被证伪；成功服务定义为同一授权交易在预先登记且版本冻结的固定 SLA 内完成（无公开 SLA 则该交易排除），规则内容按官方版本的六字段规范化编码（适用范围、许可、义务、限制、执行程序、救济结果；空值、例外和版本号作为每条记录的固定元数据保留），切换直接货币成本为费用加迁移工时乘预注册统一时薪，法域间比值为各法域中位数除以最低中位数；若不是测量口径造成，则不以单一协议或文本相似作为证伪。
- **领先指标**：每年在同一组预先登记的至少三个制度差异显著法域和同一组交易上（跨境数据传输、算力服务、关键基础设施服务各至少一种；同一服务规格、提供者—客户对、跨境路线、每年 12 个月观测，排除测试、演示和一次性交易），逐项记录四类规则的六字段规范化内容（适用范围、许可、义务、限制、执行程序、救济结果；空值、例外和版本号作为每条记录的固定元数据保留）；记为 `S=1` 仅当四类内容在三个法域均完全相同。成功服务定义为同一授权交易在预先登记且版本冻结的固定 SLA 内完成（无公开 SLA 则该交易排除），计算成功服务可用率的最大法域间差异 `ΔA`；切换直接货币成本为费用加迁移工时乘预注册统一时薪，分别计算法域中位数除以最低中位数的 `R_money`，并计算中位耗时比值 `R_time`。仅当连续两年 `S=1`、`ΔA ≤ 5` 个百分点、`R_money ≤ 1.2`、`R_time ≤ 1.2` 时，才报告与证伪条件相同的反向信号；任一条件缺失都不算证伪信号。
- **置信度**：中
- **depends-on**：J-059, J-060, J-061, J-062
- **最强反方**：跨国企业、互认标准和供应多元化可能把关键依赖变成可替代商品，使制度差异停留在文本层而不影响现实可用性；重大危机也可能反向促成广泛统一规则。
- **与共识**：本轮未完成外部对照；独立推演与“关键技术供应链会受到国家政策影响”的一般判断一致，但不把现有出口管制或联盟承诺直接外推为长期分区，更不把制度分区等同于战争；坚持以可执行许可、切换成本和实际服务可用性检验。
- **外部对照来源**：未完成对照；待登记各法域跨境数据、算力、关键基础设施许可与采购规则的时间序列来源。
- **外部对照状态**：INCOMPLETE_NOT_ATTEMPTED；来源集合：NONE。缺口：尚未完成跨法域规则变更、互认与实际可用性的统一序列；下一步：登记至少三个制度区的许可、采购、标准和服务可用性数据，再更新状态。
- **出处**：[C20 边界先于能力](../chains/200-law-property-liability-and-geopolitics.md#3-推演链能力扩张先制造边界争议制度以分层许可和责任承载回应)
- **下次检查日**：2029-12-31
- **状态**：ACTIVE
