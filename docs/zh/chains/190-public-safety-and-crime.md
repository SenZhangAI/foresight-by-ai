# C19 · 公共安全与犯罪：安全不会被单一技术自动生产

[English version](../../en/chains/190-public-safety-and-crime.md)

**未使用的透镜**：无——本链同时使用 L1 供需关系、L4 历史规律、L5 社会规律、L8 人性规律与 L9 制度和权力；AI 与「丰富→稀缺」不作为额外发动机。

> **链的入口**：公共安全不是“犯罪率会不会下降”这一条曲线。先把暴力、财产犯罪、线上诈骗、家庭与性暴力、公共空间安全和执法合法性分开，再问人口结构、城市机会、制度能力与技术变化怎样改变每一类风险。安全感、实际受害和国家记录也不是同一分母。

## 1. 先把问题拆开

至少要同时观察五件事：

1. **实际伤害**：暴力、盗窃、诈骗、家庭与性暴力等事件的发生率和损失；
2. **暴露与报告**：谁暴露在风险中，谁愿意报案，哪些受害永远不进入行政记录；
3. **空间与关系**：风险发生在街道、家庭、工作场所、平台还是跨境网络；
4. **治理反应**：警察、法院、监狱、社区组织、平台和保险如何分工，执法是否可申诉；
5. **安全感与信任**：人们是否因此改变出行、交易、邻里交往和对陌生人的信任。

如果只看报案数，执法变强和报案意愿变高会被误读成犯罪上升；如果只看治安感，媒体曝光和政治动员会被误读成实际风险上升。

## 2. 历史回看：有效下降与风险转移可以同时发生

历史材料先支持一个有限机制：风险会随机会结构、人口结构、治理能力和作案工具变化而重组；单独增加警力或单独引入新技术，不能保证总伤害下降。

- **机制成功案例一（待复核）**：1990 年代美国部分大城市的暴力犯罪长期下降，与人口年龄结构、就业与空间治理、警务方式和毒品市场变化共同出现。它支持“多重中介同时改变，某类暴力才可能下降”，不支持把下降归功于一种警务技术。
- **机制成功案例二（待复核）**：战后日本长期较低的致命暴力与社区规范、人口结构、武器可得性、警务可达性和社会控制共同相关。它支持“低犯罪需要一组制度与社会条件”，不支持把一个国家的结果直接外推到所有城市。
- **失败对照一**：美国“严厉禁毒—大规模监禁”路径没有把更强惩罚自动转化为所有类型犯罪的持续下降，并产生了新的家庭与社区代价；它反驳“惩罚越重，安全必然越高”。
- **失败对照二**：互联网、身份认证和反欺诈技术不断增加，但跨境网络诈骗仍可扩张或转移；它反驳“检测能力变强就会自动消灭线上犯罪”。

这四组案例只校准候选机制，尚未完成统一口径、时间窗和反事实的可复核登记。它们的作用是筛掉“单一技术决定安全”的规则，而不是替未来结论制造虚假的确定性。

## 3. 推演链：可见暴力与线上损失会分化，治理能力决定是否转化成安全

人口老龄化和城市空间变化改变暴露结构 → 教育、就业与社区支持改变可进入的机会与冲突场景 → 警务、法院、平台和保险改变发现概率、报案成本与损失回收 → 传感器、身份系统和生成式工具一方面降低取证与防御成本，另一方面降低诈骗和伪造的门槛 → 犯罪从街道、家庭、机构和平台之间重新分配，受害统计与安全感发生偏离 → 只有当跨部门责任、申诉、跨境追索与受害者支持同时可用时，技术带来的“发现更多”才可能变成实际伤害下降，而不是记录增长或风险转移。

这里的关键约束是：更多摄像头、模型和数据不能替代合法授权、可信报案、跨机构协作和对错误执法的纠正；把“预测到风险”直接当作“证明谁有罪”，会把公共安全变成新的权力风险。

## 4. 可读的未来场景

- **近端（2027–2030）**：部分高收入城市的可见街头暴力可能继续下降或保持低位，但老年人、移民、小商户与数字平台用户承担的诈骗、身份盗用和有组织财产犯罪更容易进入公共议程。报案率、平台拦截率和实际损失会同时变化，不能只看一个数字。
- **中端（2030–2035）**：警务技术会从“发现更多”转向“能否解释、申诉、纠错和跨境追偿”。能把平台、银行、警察、法院和受害者支持连起来的制度，可能减少损失；只增加自动化监控而没有责任边界的系统，可能提高误伤和不信任。
- **更远端**：公共安全可能分成两套并行账本：物理空间的暴力与秩序账本，以及信息空间的身份、支付、勒索和操纵账本。两者都影响出行与陌生人信任，但不必然由同一机构、同一技术或同一政策解决。此处仍是图景，不是“犯罪必然上升”或“技术必然带来安全”的结论。

## 5. 所以现在可以做什么

- **研究者**：建立至少四个地区、每个地区至少两个社会的共同面板，把 victimization survey、报案、平台诈骗损失、致命暴力、执法接触和安全感分开；先固定定义、分母和报告偏差，再比较趋势。
- **公共机构**：把线上诈骗与线下暴力作为不同治理链，公开拦截、误报、追偿、申诉和受害者支持指标；任何自动化识别都要同时记录错误率、异议渠道和责任主体。
- **城市与平台管理者**：不要把摄像头数量或模型召回率当作安全结果；在部署前写出可撤回边界、人工复核、数据保存期限和受害者补救路径。
- **普通读者**：遇到“警察更多所以更安全”“AI 监控会消灭犯罪”或“报案增加所以犯罪上升”的说法，先问它谈的是实际受害、记录、损失、恐惧还是治理能力。

## 6. 判断边界

本链目前只有一条正式判断卡（J-119）。它不预测全球犯罪率的单向升降，而是判断 2027–2035 年风险重组是否会先于整体安全改善：部分可见暴力下降、线上诈骗和身份型财产损失扩张或转移，最终结果取决于治理、追偿与合法性。历史案例已用于提出两组成功与两组失败对照，但尚未完成统一跨国数据库、受害者分母和外部来源登记；如果这些口径无法对齐，证伪状态必须记为不可判定。
