## 已覆盖的三条独立入口

### 1. 文化、娱乐与闲暇：时间预算先于内容供给

**问题入口**：当可支配时间、收入和注意力习惯变化时，哪些娱乐从小众变成社会规模？

**已覆盖判断**：J-112 只覆盖城市中等收入成年人参加线下文化活动的时间与价格约束，以及短视频／流媒体替代部分闲暇时段的可检验方向。它不声称某一平台、类型或国家必然胜出；没有跨国时间使用与付费数据的部分仍是仅图景。

文化场馆的地理可达性、票价、照护责任和工作时长 → 可用于娱乐的连续时间被切碎 → 低摩擦、可暂停的媒介获得选择优势 → 但现场参与仍由社交、身份和空间共同生产。领先指标是时间使用、票价负担、场馆到达时间与重复参与率。

### 2. 气候与环境：风险通过保险、能源和迁移传导

**问题入口**：极端天气、能源价格和适应投资如何改变住房、健康、食品与迁移？

**已覆盖判断**：J-113 覆盖高暴露地区的家庭与地方政府会先通过保险缺口、适应投资和出行中断承受环境冲击；它不把具体灾害发生写成确定事件，也不把某项技术当成必然解决方案。

物理暴露与基础设施脆弱性 → 损失与保险价格上升 → 低收入家庭和财政薄弱地区先削减非必要消费或迁移 → 适应投资若及时可缓冲损失，否则风险转成住房、收入与公共安全压力。指标包括保费、停电／道路中断、适应支出、食品价格和迁移流量。

### 3. 交通与日常出行：距离、密度与能源价格的制度约束

**问题入口**：通勤、照护和购物的日常移动如何受公共交通、道路容量、能源价格与居住分布共同塑造？

**已覆盖判断**：[J-122](../ledger/122-122.md#j-122--日常出行先按可靠性与照护责任分层而不是自动转向单一方式) 把交通从问题入口推进为一张独立判断卡：2027–2035 年，可靠性、可负担性、居住密度与照护责任更可能造成家庭出行分层，而不是全体自动转向某一种方式。它不把现有具身智能卡片重复计为交通覆盖。

居住分布与照护责任固定了必须发生的出行 → 道路容量、公共交通班次、能源价格和极端天气共同改变可靠性与成本 → 时间余量更少、照护责任更高的家庭先吸收等待、换乘与取消风险 → 家庭组合多种方式并调整活动半径，而不是因某项技术出现就同步换成一种方式。领先指标是按收入与照护责任分组的可靠性、总出行时间、费用／收入比、服务中断、照护出行可达率、方式组合与取消率。

**仍未闭合的边界**：J-122 尚无独立外部对照来源；跨城市共同家庭分母、长期可靠性、可负担性与照护出行面板仍缺。因此交通已有可达判断入口，但不等于城市交通或自动驾驶的全景预测。

## 尚未覆盖的子域与下一步缺口

- **宗教与信仰**：已转入独立 [C17 宗教与信仰](170-religion-and-belief.md)，由 [J-117](../ledger/117-119.md#j-117--宗教先分化与重组不会随现代化全球同步消退) 覆盖归属、实践、制度载体与规范身份；跨国长期序列仍缺。
- **公共安全与犯罪**：已转入独立 [C19 公共安全与犯罪](190-public-safety-and-crime.md)，由 [J-119](../ledger/117-119.md#j-119--风险会先重组公共安全不会由单一技术自动改善) 覆盖实际风险、报告概率与制度响应；跨国长期序列仍缺。
- **收入、财富分配与不平等**：已转入独立 [C18 收入、财富与不平等](180-income-wealth-inequality.md)，由 [J-118](../ledger/117-119.md#j-118--生产率增长先分化取得权再决定收入是否扩散) 先判断生产率如何分化取得权，再追踪税制、住房、劳动议价与公共服务是否让收益扩散；跨国长期家庭分位面板仍是缺口。

因此，C16 目前是「三条独立问题入口，三条均有判断卡，但气候与交通的跨城市证据仍不完整；公共安全与犯罪已转入 C19，收入与财富分配已转入 C18」；它不是六个维度都已完成的总预测。
