# C20 · 边界先于能力：法律、产权、责任与地缘制度如何决定谁能行动

[English version](../../en/chains/200-law-property-liability-and-geopolitics.md)

**未使用的透镜**：无——本链同时使用 L1 供需关系、L4 历史规律、L5 社会规律、L7 制度与权力规律和 L8 人性规律；技术能力和「丰富→稀缺」只作为改变交易对象与议价筹码的力量，不作为唯一发动机。

> **链的入口**：当交易对象从土地、机器和服务扩展到数据、模型产出、跨境代理与关键基础设施时，先变化的未必是能力，而是“谁可以使用、谁可以许可、谁为事故负责、哪个制度有权裁决”。本链承接法律、产权、责任与跨境制度的边界，不重复 C14 对选票、安全预算和国家安全触发后的制度响应，也不把 C11 的代理授权判断再写一遍。

## 1. 先把四种边界分开

1. **使用权**：谁能访问数据、模型、接口或关键基础设施，访问能否撤回；
2. **收益权**：谁能许可、定价、转让或从模型产出中获得剩余收益；
3. **责任权**：发生伤害时，谁有能力补救、谁承担举证、保险与赔偿；
4. **裁决权**：跨境服务、数据流和基础设施依赖发生冲突时，哪个国家、法院、平台或标准组织能实际执行决定。

把这四者压缩成“数据属于谁”或“AI 是否有主体资格”，会把不同的法律问题和不同的权力载体混成一个口号。

## 2. 历史回看：新交易对象通常先长出分层权利，跨境冲突不会自动统一

历史材料支持一个有限的候选机制：当新交易对象具有可复制性、外部性或跨地域依赖时，制度常把访问、收益、责任和裁决拆成不同层次；统一产权口号并不等于统一执行。

- **机制成功案例一（待复核）**：专利制度把公开、排他、期限与许可拆开，支持“知识交易需要一组相互牵制的权利”，不支持所有创新都能被单一产权形式解释。
- **机制成功案例二（待复核）**：航空与跨境通信等网络行业以许可、互联、责任与国家管辖共同组织服务，支持“基础设施先形成可执行的边界组合”，不支持全球规则会自然同质化。
- **失败对照一（待复核）**：跨境互联网服务的隐私、内容与数据转移规则长期分化，反驳“网络可复制性会自动带来统一产权与责任”。
- **失败对照二（待复核）**：软件许可与开源协议能清楚授予部分使用权，却不能单独解决训练数据来源、模型输出侵权或跨境事故赔偿，反驳“写一份许可文本就能闭合全部责任”。

以上四组是待登记来源的校准候选，不把机制候选冒充已完成的 2+2 历史验证。若统一定义、案例来源或反事实无法补齐，相关判断保持开放或降级为仅图景。

## 3. 推演链：能力扩张先制造边界争议，制度以分层许可和责任承载回应

数据与模型产出可复制、但其来源、隐私、训练贡献和现实后果不可完全复制 → 交易双方把访问、使用、收益和撤回拆成不同权利 → 高责任场景继续依附既有组织、保险与人工复核，而不会因为模型更强就自动生成独立主体资格 → 跨制度代理事故暴露举证、追偿和管辖冲突 → 国家把算力、数据、芯片、云服务与关键基础设施当作议价筹码，通过许可、出口管制、采购、标准和本地化要求重写可用边界 → 社会看到的不是一套全球统一规则，而是多个可互操作程度不同的制度区。

这条链的边界是：它不预测哪一个国家或平台必然获胜，也不把 C14 的选举与安全预算判断扩张为战争、核威慑或全球极化预测。它只判断交易对象和跨境依赖会把法律、产权、责任与裁决权推到同一张制度账本上。

## 4. 可读的未来场景

- **近端（2027–2030）**：高责任行业先把模型使用写进合同、审计、保险和撤回流程；数据和模型产出的争议更多表现为许可范围、训练来源、可解释记录和事故赔偿，而不是抽象的“AI 是否拥有产权”。
- **中端（2030–2035）**：跨境服务按制度区分可用能力。企业不只比较模型效果，也比较数据能否跨境、事故由谁补救、供应能否持续、争议由谁裁决；“合规接口”和“可证明的责任承载”可能成为基础设施。
- **更远端**：关键基础设施和高价值数据的控制权可能成为国家与大型组织的长期议价资产。不同制度之间会保留互认协议，但不会自然收敛成一套世界产权法；这一段是图景，不是对战争或某个国家政策的断言。

## 5. 所以现在可以做什么

- **研究者**：为数据访问、模型输出、跨境代理事故和关键基础设施依赖分别建立事件面板，不把法律文本数量当作执行效果；先记录许可、撤回、事故、赔偿与跨境执行的共同分母。
- **企业与公共机构**：在部署前把使用权、收益权、责任权和裁决权分栏写入合同与日志；对跨境服务预先标记数据出口、供应中断和争议解决的替代路径。
- **读者与审查者**：遇到“AI 会自动成为产权主体”或“全球规则会很快统一”的说法，先问它具体谈的是访问、收益、责任还是裁决，以及谁能在现实中执行。

## 6. 判断边界

本链新增两条正式判断卡：J-120 处理数据、模型产出与跨制度代理事故的分层权利和责任边界；J-121 处理关键基础设施、数据与算力作为跨境议价筹码的制度分化。两条卡都保留“外部对照未完成”和实际重复行动分母的证据边界；它们补充而不替代 C11、C13、C14 的既有判断。
