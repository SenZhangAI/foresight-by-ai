# 技术能力演进链

> 首轮技术链入口。它回答「什么先到、因此什么才可能、接着是什么」，不把技术后果重复写进时间层正文。

## 初始链条

1. 单位推理成本继续下降（J-TECH-001）。
2. 生成更多候选并覆盖代码、图像、视频和执行计划。
3. 可形式化的质量筛选被模型内化，通用质检成为窗口机会（J-SCAR-001）。
4. 复杂工作流开始触碰私有上下文与不可逆动作，产权和回滚成为新的约束（J-SCAR-002、J-SCAR-003）。

## 仍待验证

本链的时间窗、硬件与能源约束、以及从建议到自主执行的采用滞后，需要下一轮研究补齐。新增技术判断必须在台账登记，并写出领先指标与证伪条件。
