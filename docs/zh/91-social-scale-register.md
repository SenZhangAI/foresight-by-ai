> **当前已过闸一（社会级）判断：0 条。**
> 取数日期 2026-10-09，口径与复算方式见[第一节](#一这个-0-是怎么数出来的)。全库 102 张在册判断卡逐卡自数，可用 `python3 scripts/count-social-scale.py` 复算。

[English version](../en/91-social-scale-register.md)

**0 是本页最重要的信息，不是本页的失败。** 这个档案给「不通过」建了登记、计数和复审（见[判断台账 · 检查日志](90-ledger.md#八检查日志)），却一直没有给「通过」建一个对称的面——读者看得见一张否决网，却无法判断它是严谨还是空转。本页就是那个面：它写出通过数，写出每一条候选卡在哪一闸、差什么，以及**要过闸必须观察到的那个可数事实**。

本页**不新增任何判断，也不改动任何既有判断的闸位**。它只汇总与导航；所有字段以[判断台账](90-ledger.md)与 `ledger/` 卡片正文为准。

## 一、这个 0 是怎么数出来的

**分子的定义**（三条同时成立才计入）：

1. 卡片的「普及闸复核」字段写明**闸一通过**；
2. 该通过**未被就地收回**；
3. 该卡不是「仅图景」——置信度不是 `低` 或 `低（仅图景）`。[方法论](00-method.md#4-判断卡片五件套与编号)规定缺项或低置信度的条目只能标为「仅图景」，不得作为判断使用，所以一张仅图景卡即使闸一通过，也不构成可用的社会级判断。

**逐卡自数的结果（2026-10-09，全库 102 张卡）**：

| 口径 | 条数 | 说明 |
|---|---|---|
| 「普及闸复核」写「闸一**不过**」 | **98** | 一律按职业／组织性、制度性或仅图景判断书写 |
| 「普及闸复核」写「闸一**过**」 | **4** | `J-029`、`J-042`、`J-053`、`J-054` |
| ↳ 其中社会级书写许可已被就地收回 | 1 | `J-029`，2026-10-09 隔离盲判复审就地纠正 |
| ↳ 其中置信度为 `低` 或 `低（仅图景）` | 3 | `J-042`、`J-053`、`J-054`，卡内自写「不把它当作……社会级结论」 |
| **已过闸一且可作社会级书写的判断** | **0** | 以上两类都不满足分子定义 |

**怎么复算**：运行 `python3 scripts/count-social-scale.py`（零依赖、只读、秒级）。它逐卡读「普及闸复核」「置信度」「状态」三个字段，分别对中英两套投影计数并打印清单；本页所有数字都应与它的输出一致。不想跑脚本的读者可以手数：在 `docs/zh/ledger/` 里检索 `闸一**过**`，命中四张，再逐卡看置信度与状态说明。

**这个 0 不说什么**：它不说社会级趋势不存在，也不说本方法已被证伪。它只说一件事——**本档案目前没有一条判断满足它自己写下的社会级门槛**。

## 二、什么才算「过闸一」

闸一的门槛是本档案自己写下的，不是本页新定的。[历史回顾 · 闸一](01-retrospect.md#闸一--先数人再看技术)在逐闸判定表里写明的社会级门槛是：

> **十亿人日频，或亿级人周频**

对照对象必须是**同一个明确定义的动作**，并且要能去重计数、有可核验来源、写清频次。两个常见的不合格形态在本档案里都已登记：把多个不同动作合并计数（例如把农业、家政、搬运、照护、建筑的劳动人口加总成「十亿」），以及把**受影响人口**（影响面）当成**实际重复执行者**（行为分母）。

还有两条规则决定了这一页为什么只能长成现在这样：

- **五道闸是否决式筛选器，不是充分条件预测器。** 任一道不过就必须收窄受众；五道全过也只表示有资格继续竞争（见[方法论 · 普及闸不是第十种可选透镜](00-method.md#普及闸不是第十种可选透镜)，以及判断卡 `J-066`）。所以本页永远不会出现「这条一定会普及」。
- **闸一不过 ≠ 这条判断错了。** [历史回顾](01-retrospect.md#闸一--先数人再看技术)用专业影视剪辑软件说明过：它过不了闸一，天花板就是剪辑师的人数，但它在剪辑师中间的普及率接近 100%，是一门好生意。不过闸一的正确读法是：**天花板等于那群人的规模，它不会成为社会风气。**

## 三、逐字回答一个问题：AI 哪有那么多要决策的人

本项目收到过这样一条质疑，原话逐字引用：

> 我完全没想到有一个通用的，能成为整个社会风气的趋势，手机能成为趋势，在线直播能成为趋势，AI 哪有那么多要决策的人？

**回答：按本档案自己的门槛，现在确实是 0 条。这条质疑成立，而且它已经改写了这个档案。**

它指出的东西是具体的：本项目 C1 链的开篇写一位市场负责人拿到六十套方案、花两个下午什么也没决定，并由此推出「选择与取舍变得稀缺」。[历史回顾第七节](01-retrospect.md#七用这道闸检验我们自己写过的东西)把这条拿去机械数人——动作定义为「面对一批已生成的候选方案，选定一个并为结果负责」，同时满足「职业要求批量产出候选、本人有拍板权、频次至少每周一次」的人集中在几类岗位的决策层，全球量级是**百万级、周频**，对照十亿日频／亿级周频差两到三个数量级。结论是它登记为 `J-072`，一条职业性判断，不得以「整个社会」口吻书写。随后 2026-09-20 的复核把这把尺子推到全库，才有了本页第一节那个 98。

**「什么样的观测会让它不再是 0」**——这是本页能给出的最有用的东西，而且它不是本页新编的判据，同一节已经写出了方向：

> **那什么才在社会级？** 同一条链上，过得了闸一的不是「选」，是「做」。「需要一份能用的材料、图、文案或程序」——这件事十亿人偶尔要做，而且此前大多数人**做不了**。它属于「让原本不会的人也能做」那一类，天花板才是社会级的。

把这句话变成可数事实，要观察到的是**同时成立**的四项，缺一项就仍然是 0：

1. **一个动作，不是一类场景。** 动作要能写进一句话并被第三方照着数（手机的那个动作是「随身携带并随时查看一块屏」，直播的那个动作是「打开一个直播间看别人实时做事」）。
2. **去重的行动者分母达到门槛。** 十亿级去重个人日频，或亿级去重个人周频，执行**同一个**上述动作。是人数，不是设备数、账号数、调用次数或「受影响人口」。
3. **可核验来源与观察窗。** 分母来自可引用的统计或可复算的测量，写明口径、时点与频次，而不是构造式推算。
4. **闸二至闸五不判否。** 它替掉了一个真实旧动作（闸二）、承载物已因别的理由被建好（闸三）、采用不需要别人同时改变（闸四）、每次的持续净负担相对真实 incumbent 不为正且可观（闸五）。

本页刻意**不**点名「哪一条最可能先过」——在历史校准与隔离重审收口之前，本项目不新开产生预测的前线，点名就是新增一条未经校准的判断。第四节给出的是每条候选自己的那个可数事实；谁先被观测到，就由观测决定，不由这一页决定。

### 第五组 · 判断对象不是个人可重复动作

**差什么**：差一套判据，而这个空缺是登记在案的，不是默认通过。这一组讲的是制度安排、资源与收益分配、授权与责任、风险定价——它们没有「一个人每周执行一次」的形态，所以闸一的「数人」判据对它们**没有可用形状**。本档案已明确登记：收益分配、风险定价、人性常数／需求侧锚点与方法规则本身这四类主张目前没有任何可判否的判据（见[方法论 §2](00-method.md#普及闸不是第十种可选透镜)与[台账 §6.2](90-ledger.md#62-隔离盲判复审登记的方法与流程缺口2026-10-09)）。在那套判据建立并完成历史校准之前，这一组既不会通过，也不该被当作已通过。

## 五、本页不改判：这些矛盾已登记待裁

本页只汇总与导航。逐卡自数过程中发现以下不一致，**一处未就地改判**，全部留给判断的维护流程处理：

1. **`J-042`、`J-053`、`J-054`：闸位标注与卡身互斥。**「普及闸复核」写「闸一**过**——可作社会级判断书写」，而同卡置信度为 `低`／`低（仅图景）`、标题带「（仅图景）」、「所以现在可以做什么」写「不把它当作已验证趋势、社会级结论或商机」。本页按字段规则把三张排除在分子之外、并在第一组公开标注，未改动任何闸位。**这三张就是「0 条」与「3 条」之间的全部差额。**
2. **「普及闸复核」字段与同卡隔离盲判记录不同步（至少 12 张）。** `J-011`、`J-019`、`J-026`、`J-028`、`J-064`、`J-065`、`J-066`、`J-069`、`J-070`、`J-089`、`J-090`、`J-094` 的该字段只记录了闸一，而同一张卡的隔离盲判复审写明裁定 `VETO`、否决闸位为闸二（`J-066` 为闸一与闸二）。处置多写作「盲判复现现有限定」，但卡上并没有一条已登记的闸二限定可供「复现」。本页第四节的「卡在哪一闸」列按卡片正文把闸二一并写出，未新增任何闸位裁定。

## 六、怎么让这个 0 不再是 0

这条通路有先后，不能跳步：

1. **先拿到一个合格的分母。** 从第三组挑一条，按它最后一列的那个可数事实去测：一个明确定义的动作、去重的行动者、写明频次与时点、来源可引用。拿不到就如实写「未知」，不要把影响面当分母——这正是这些卡现在的卡点。
2. **再过闸二至闸五。** 过了闸一只是规模达标。它替掉了什么、承载物由谁建、采用需要谁同时改变、每次的持续净负担相对真实 incumbent 是正还是负，四问都要有答案；写不出解锁条件的，不得只把年份往后推。
3. **最后才取得社会级书写许可，而且它仍然可以被收回。** `J-029` 就是在取得之后被收回的：许可来自判据，不来自口吻。

与此并行的是第五、第六组欠的那套东西：**给「制度与分配类主张」建立可判否的判据，并按本项目的规矩先用历史案例校准**（每条至少 2 个成功案例 + 2 个失败案例，并且必须能对某些真实案例判否）。这套判据不建立，这两组就会一直停在「没有判据」而不是「已通过」。

## 七、本页的边界

- 本页是**汇总与导航面**，不是第二份台账。任何数字、字段与闸位结论以[判断台账](90-ledger.md#二在册判断总览)和 `ledger/` 卡片正文为准；两处不一致时，以卡片为准并修正本页。
- 本页的分组是阅读投影，不是新的判定层。把一张卡从一组移到另一组不改变它的闸位。
- 第四列「差什么」与第五列「可数事实」是**对现有卡片字段的提炼**，不是新判断、不进台账、不带时间窗与置信度。它们可以被攻击；攻击的方式是指出某一行与它所引卡片的字段不符。
