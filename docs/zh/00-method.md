# 推演方法论

> 这份文件规定**怎么推演**，不含任何具体结论。具体结论在 `chains/`。
> 改这份文件 = 改游戏规则，属于重大变更，commit message 必须写清改了哪条规则、为什么。

---

## 0. 这个项目在跟什么东西打架

未来图景满大街都是。它们的通病是：**给结论，不给推理链；给方向，不给时间窗；说对了说错了，事后没人能判定。**

所以本项目的差异化不在「结论新颖」，而在**可证伪**。一条判断如果半年后无法自检对错，它就不是判断，只是感想。

---

## 1. 推理的合法起点

允许作为论据的：

- **供需关系**：任何东西变得丰富，它的价格趋近于边际成本；与它互补的东西价格上升。
- **人性常数**：地位竞争、损失厌恶、对确定性的付费意愿、对身体在场的偏好——这些在有记载的历史里没变过。
- **历史规律**：技术扩散的 S 曲线、学习曲线（累计产量翻倍则单位成本下降固定比例）、制度总是滞后于技术、每次生产力跃迁都先造成失序再造成新秩序。
- **技术规律**：可并行的确定性计算，成本必然下降；不可并行 / 需要真实世界介入的环节，成本下降慢得多。
- **社会规律**：当一种信号变得容易伪造，社会会退回到更昂贵、更难伪造的信号。

**不允许**作为论据的：

- 「某机构预测……」「某某人认为……」——不论那个机构多权威。
- 任何以「大家都知道」开头的句子，除非同时标注它为什么成立。

### 1.1 共识标注（诚实边界）

写这些文字的是一个语言模型，它的记忆本身就是人类已有判断的压缩，**做不到 100% 不参考**。能做到的是：

- 推理从上面那些底层规律起步，不引用他人预测当论据；
- **当结论与主流共识重合时，显式写上「与共识一致」**，不伪装成独立发现。

不标注的后果：半年后你无法分辨哪些是真推演、哪些是在复述记忆——而这恰恰是这个项目唯一的价值。

### 1.2 外部对照的顺序

先独立推演，**再**去看外部判断。对照结果写成显式段落：**一致 / 分歧 / 我为何仍坚持**。顺序不可颠倒——先看外部再推演，等于放弃独立性。

## 2. 透镜工具箱：八种看未来的方式

一个框架看什么都像那个框架。所以这里备了**八个**，每条推演链开头必须声明它用了哪几个，**并说明为什么这几个而不是别的**。

用得最顺手的是 L1（这个项目就是从它起步的），但它有明确的适用边界，见下。

### L1 · 丰富 → 稀缺（互补品定价）

某样东西变便宜、变多了；**与它互补、却没有同步变多的那样东西，价格上升。**

- 擅长：供给侧发生剧变时，快速定位价值往哪儿跑。
- **边界**：它假定需求结构不变。当变化大到改写人们**想要什么**时，L1 会失灵——这时用 L8。
- 它还有个陷阱：不是所有新稀缺都能变成机会（见第 3 节的闸门）。

### L2 · 约束迁移（瓶颈会跳，不会消失）

任何系统的产出由**最紧的那个约束**决定。解除一个约束，系统不会均匀变快，而是**瓶颈整体跳到另一个环节**——而且常常跳到一个此前根本没人管理的环节。

- 擅长：预测「会冒出什么新岗位、新品类、新工具」。L1 只能告诉你什么升值，L2 能告诉你**哪里会长出一个原本不存在的东西**。
- 例：生成产能的约束被解除后，瓶颈跳到「取舍」——而过去没有任何岗位、任何工具专门负责取舍，因为方案本来就少到可以逐个人工判断。

### L3 · 成本结构决定形态（不是能力决定形态）

组织和产品长什么样，由**协调成本与交易成本**决定，不由技术能力决定。企业之所以存在，是因为在市场上一次次谈判比内部指挥更贵。

- 擅长：推演公司规模、雇佣关系、外包边界、产品的打包方式如何变化。
- 关键问法：这项技术降低的是**内部协调成本**还是**外部交易成本**？两者降低的方向不同，组织会朝相反方向变形。

### L4 · 扩散滞后（能做 ≠ 在做）

能力出现和被普遍采用之间有一段可预测的滞后，长度主要由三样东西决定：**被替换资产的折旧年限、监管周期、人的技能形成周期**。

- 擅长：给时间窗。这是把「方向判断」变成「可下注判断」的关键透镜。
- 粗口径：纯软件替换以月计；需要换硬件的以年计；需要换人的技能结构的以十年计；需要换法律的，看立法周期而不是技术周期。

### L5 · 信号与伪造（昂贵才可信）

一个信号能当筛选凭据，是因为**伪造它很贵**。伪造成本一旦塌掉，信号立刻失效，社会会退回到更昂贵、更难伪造的下一层凭据。

- 擅长：推演文凭、作品集、推荐信、书面表达、认证、身份这些东西的命运。
- 强推论：当「说得好」变得免费，社会不会因此停止筛选——它会去找**下一个还很贵的东西**，通常是担保、抵押、长期关系、身体在场。

### L6 · 不可逆性与试错经济学

「多试几次然后挑」这个策略，只在**结果可撤销**的地方成立。单次成本降到零，在不可逆的地方不产生任何好处——因为那里的代价从来不是单次成本，而是损害。

- 擅长：切开「哪些领域会被便宜的生成彻底改写，哪些几乎不动」。这条切线比按行业分类有用得多。

### L7 · 制度滞后与租金窗口

技术先行，制度滞后。滞后期内会出现**租金**（规则还没写好，先做的人拿走超额收益）；制度落位时租金消失。

- 擅长：判断一个机会**什么时候关闭**——这跟判断它什么时候打开一样重要，而多数报告只写前半段。

### L8 · 人性常数（需求侧的锚）

供给可以翻天覆地，需求侧有几样东西在有记载的历史里没变过：**地位竞争、对稀缺本身的偏好、对真实在场的偏好、损失厌恶、把责任推给某个人的需要。**

- 擅长：当 L1 失灵（需求结构被改写）时接手。也用来做「反向校验」：如果一条推演的结论要求人性发生改变，这条推演多半错了。

### 怎么选透镜

| 你要回答的问题 | 首选 |
|---|---|
| 价值往哪儿跑 | L1 + L2 |
| 会长出什么新品类／新岗位 | L2 |
| 组织和雇佣关系会怎么变 | L3 |
| 这件事什么时候真的发生 | L4 |
| 什么时候不再是机会 | L7 |
| 哪些行业几乎不动 | L6 |
| 凭据、声誉、身份会怎样 | L5 |
| 人们会不会真的想要 | L8 |

**声明透镜是强制的。** 一条链如果八个都用，通常意味着它没有真正的论证主轴，只是在堆砌。

## 3. 闸门：这个新稀缺，能被制造丰富的同一股力量自动化掉吗？

不论用哪个透镜推出了「某某变稀缺」，都必须过这一道闸。这是绝大多数未来报告漏掉的一步。

- 答案是「**能**」——它不是商机，只是一个 2~4 年的**窗口**。可以吃，但不能当结构性机会去下注。明确标为「窗口」。
- 答案是「**不能，因为……**」——必须指名是哪一类**硬约束**：

| 硬约束 | 为什么自动化吃不掉 |
|---|---|
| **物理** | 需要在真实世界中在场、移动质量、消耗能量、等待时间流逝 |
| **法律／责任** | 责任只能由能被起诉、能赔钱的法人承担，算法承担不了 |
| **信任／关系** | 需要长期重复博弈积累，无法一次性生成 |
| **产权／私有性** | 关键输入被他人合法持有，且不愿或不能交出 |
| **身体在场** | 人类对「有人真的在这里」的偏好本身就是需求 |
| **不可逆性** | 错了无法撤销，因此试错的成本不是算力而是现实损失 |

没能指名硬约束的，一律回落为「窗口」。**宁可少一条候选，不要多一条假机会。**

## 4. 判断五件套（格式强制）

每条判断都写成一张卡片，嵌在叙事里。**缺任何一项，这条只能标为「仅图景」，不得当判断使用。**

```
> **J-XXX-000 · 一句话标题**
> - **时间层**：近期／中期／远期（起止年份）
> - **透镜**：用到哪几个（L1–L8）
> - **推理链**：从哪条底层规律出发，经过哪几步，得到这个结论
> - **时间窗**：这件事在哪个区间内发生；过了就算没发生
> - **证伪条件**：观察到什么，我就承认这条错了（必须是可观察事件，不是感觉）
> - **领先指标**：在结果出现之前，什么先动？盯哪个数
> - **置信度**：高／中／低
> - **依赖**：本判断成立所依赖的其他判断 ID（远期判断几乎一定有依赖）
> - **与共识**：一致／分歧／未知
> - **状态**：ACTIVE／HIT／FALSIFIED／REVISED
```

## 5. 置信度纪律（比框架更重要的一节）

置信度不是修辞副词，是**这条判断值多少注**。它有三条硬规则：

**规则一：三档有严格定义。**

- **高**：要推翻它，需要一个我现在完全想不到的新机制。通常意味着这条判断的成立依赖**多个相互独立**的原因，不是单一原因。
- **中**：要推翻它，需要一个我已经想到、但判断不会发生的事件真的发生。
- **低**：方向性直觉，证据链不足。**低置信度一律标「仅图景」，不进商机候选，不写进摘要。**

**规则二：置信度必须与证伪条件的严厉程度匹配。**
「高置信度 + 松垮的证伪条件」是作弊——等于给自己留了永远不会触发的免责。自检问法：**照这个证伪条件，有没有一个现实的世界能让它触发？** 如果想不出，证伪条件写废了，重写。

**规则三：呈现按置信度排序，不按话题排序。**
每条链、每份摘要，高置信度的结构性判断先讲，低置信度的图景放后面并明确标注。读者的注意力应该分配给最值得下注的部分，而不是最耸动的部分。

**校准**：台账长期记录命中率。如果「高置信度」这一档的命中率明显低于「中」档，说明我系统性高估自己——这时改的不是判断，是**打分习惯**。这一条比任何单条判断都重要。

### 状态的含义

- `ACTIVE` 在有效期内，等待检验
- `HIT` 时间窗内证据支持，命中
- `FALSIFIED` 证伪条件触发，已被推翻
- `REVISED` 被新证据修正，旧版本保留在 git 历史里

**被证伪的判断永不删除。** 一份只留正确判断的档案是骗人的，命中率无法计算，项目就退化成宣传册。

## 6. 时间层定义

不按日历切，按**不确定性的来源**切：

| 层 | 年份 | 主要不确定性是什么 | 所以能说多死 |
|---|---|---|---|
| **近期** | 2026–2029 | 技术与产能都已存在，不确定的只是**速度** | 可以给较窄时间窗，置信度可以到「高」 |
| **中期** | 2029–2033 | 技术后果已定，不确定的是**社会与制度怎么反应** | 只能给方向与区间，置信度一般为「中」 |
| **远期** | 2033–2041 | 不确定的是**人类偏好本身是否漂移** | 多数只能是「仅图景」，置信度「低」 |

**时间层是卡片上的一个字段，不是目录。** 判断的时间窗会随证据移动，如果按时间建文件夹，一次修正就要搬文件，git 历史断在重命名上——而「判断如何演化」正是这里要留痕的东西。

## 7. 每条链必须有的一节：我可能错在哪

每条推演链结尾强制写**最强反方**：不是「当然也存在不确定性」这种废话，而是**一个具体的、如果成立就能整条推翻的机制**，并写明哪个观察会让我撤回。

写不出强反方，说明这条链还没想透，不要发。

---

## 8. 落地强制

每条链、每个图景段落都要落到**「所以现在可以做什么」**。

落不到的，**显式标注「仅图景」并保留**——不删除，也不伪装成可行动结论。这一条保证「全方位图景」和「可下注商机」两个目标都不被对方吃掉。

---

## 9. 表达纪律（这是公开仓库，写得难读等于没写）

严谨和好读不是取舍关系。难读的严谨，读者到第三段就走了，严谨归零。

1. **用场景开头，不用定义开头。** 一条链的第一屏必须是一个具体的、有画面的未来切片——有人、有数字、有一个卡住的瞬间。定义放到读者已经想知道答案之后。
2. **具体名词优先于抽象名词。** 写「六十套完整方案」，不写「大量产出」；写「公司已经没了」，不写「造成严重后果」。抽象名词是读者跳过的信号。
3. **每一节留一句能被单独引用的话。** 读者转发的是句子，不是章节。
4. **反方是内容，不是免责声明。** 「我可能错在哪」这一节要写得和正文一样用力——它是这份档案最稀缺的部分，也是最值得读的部分。
5. **不用「革命性」「颠覆」「前所未有」。** 这类词在公开发布时立刻掉价，且它们出现的地方通常是论证薄弱的地方。
6. **判断卡片以引用块嵌在段落之后**，视觉上明显是「可验证的附件」，跳过它也能读通全文，想验证时随手可查。
7. **长度服从论证。** 一环推演讲完就停，不为凑结构注水。

## 10. 双语与 git

- 中英双版是同一条判断的两个投影，**同一次 commit 内同步更新**。ID 语言中立，跨语言引用不断。
- commit message 记录：**改了哪条判断（ID）、依据什么新证据**。禁止 `update docs` 式流水账。
- 任何判断的状态变更（ACTIVE → HIT / FALSIFIED / REVISED）必须单独成一次 commit，这样 `git log` 本身就是判断演化史。
