# 下一研究缺口优先级

> 这是一张从现有覆盖矩阵、`J-NNN` 判断卡与演化记录投影出的研究队列，不是第二份判断台账。它回答「下一步先研究什么、为什么、做到哪一步才算有证据」，不替任何判断提高置信度。

## 这张表怎么用

当前 README 的覆盖矩阵把若干维度标为「部分覆盖」：已有入口和判断，但制度、规模、长期结果或跨地域证据仍未闭合。本页把这些已存在的缺口按公开规则排序；维度的状态、卡片编号和当前边界仍以[全景覆盖矩阵](../../README.md#全景覆盖矩阵当前边界)、链接的判断卡和[判断演化记录](03-evolution.md)为准。

「优先级高」不是「预测更可能成立」，也不是道德上的重要性排名，而是下一项研究对全景判断的**社会杠杆、上游依赖、证据缺口和可执行性**的综合顺序。研究结果可以是支持、收窄、证伪或诚实地停在 `unverified`；所有结果都比用相邻主题填补缺口更有价值。

## 排序规则

按以下顺序从高到低排序：

1. **社会重要性**：是否触及基本照护、身体劳动、制度权利、公共安全或大规模资源配置；
2. **上游依赖杠杆**：结果是否会约束多条推演链，而不只是一个局部故事；
3. **证据缺口的决定性**：缺的是否正是规模分母、制度边界、长期结果、责任或成本分摊等会改变判断的证据；
4. **可执行性**：能否在一个有明确时间点、原始材料、观察窗和交付物的研究动作中推进。

前三项形成社会研究价值，第四项用来打破「重要但永远无法核验」的平局。优先级不会由新颖性、商业可见度或当前置信度决定。低优先级项目仍然保留；它们只是排在高杠杆、可核验的缺口之后。

## 研究动作的共同验收

无论先执行哪一项，研究动作都必须留下可独立复核的材料：

- 明确的时间点 `T`、观察窗、动作定义和去重分母；
- 原始材料的稳定定位、口径与已知结局／状态；
- 至少一个可能把当前卡片收窄、证伪或降为 `unverified` 的结果；
- 对中英页面同步更新，但不复制第二套判断事实；
- 若材料只能解释已知结果，标为 `CALIBRATION`，不得写成未来准确率或样本外命中率。

如果某项研究无法同时给出这些前提，正确结果是保留缺口并说明停止原因，而不是降低证据标准来填满这张表。
