## 二、依赖图（远期踩着近期走）

```
J-TECH-001（推理成本继续降）
   ├── J-SCAR-001（筛选是窗口）
   │      └── J-SCAR-002（私有上下文是持久稀缺）
   ├── J-SCAR-003（可撤销基础设施）
   └── J-SCAR-004（三类不可重组输入升值）
              └── [待写] C2：数据合同化定价
                     └── [待写] C3：信任抵押化（远期，仅图景）
```

**这张图的用法**：**任何一条判断被证伪或修正，所有依赖它的下游判断自动进入「待重审」**，必须逐条复核，不能默认它们还成立。这是本项目「更遥远的判断必须踩着近期判断」的机械落实。
