# 项目地图与能力声明

> 这是一张公开导航地图，不是第二份判断台账。完整判断、依赖、证据和缺口仍以各链正文与 `J-NNN` 台账卡为准。

## 项目是什么

这是一个面向公众的中英双语未来社会沙盘知识仓库。它从历史校准、供需、人性、技术、社会与物理世界约束出发，沿推演链展开未来图景，并把不确定性、证伪条件和证据缺口保留下来。商机是出口之一，不是唯一主题。

## 公开入口如何分工

| 入口 | 作用 |
|---|---|
| `README.md` / `README.en.md` | 面向新读者的五分钟入口、范围说明和导航 |

| `package.json` | 声明仓库的机器可发现能力；不承载判断内容 |

## 当前能力声明

当前 `package.json` 只声明一个 `scripts.ship:*` 项：`ship:structure-placeholder`，命令为 `true`。它是为了保持公开仓库能力注册形状完整的**结构占位**，不是内容质量、证据完整度、预测准确率或项目完成度的闸门。

它的边界必须分开阅读：

- 仓库内的 `scripts/check.py`、正文、台账和覆盖矩阵不读取或汇总 `ship:`；
- 外部能力派生器可能把 `scripts.ship:*` 记录为机器能力，外部项目状态因此可能出现“已声明但尚无判决”或其他机械状态；本仓库不把该状态翻译成内容质量结论；
- 本仓库没有发布入口或 CI 发布流程把这个占位状态升级成“已发布”事实；
- 外部派生器对缺少键、`null`、`false` 或其他非字符串值的具体解析不在本仓库可验证范围内，不能从这里替它作断言。

因此，`ship:` 只表示能力注册的结构存在。是否相信某条判断、是否认为证据足够、是否接受当前图景，仍须回到公开正文、台账和历史复核，而不是看这个占位键。

## 当前边界

项目仍在扩展：全景入口、具身智能、照护、基础设施、组织、教育、生物医疗和供应链等方向已有不同程度的正文，但部分制度、规模、长期结果与跨地域证据仍明确开放。地图不会把“有入口”写成“已完成”。

## 阅读路径

1. 想快速理解范围：从仓库根目录 README 开始。
2. 想理解推演方法：读[推演方法论](00-method.md)和[历史回顾](01-retrospect.md)。
3. 想沿因果关系阅读：从任意推演链进入，再点击 `J-NNN`，沿 `depends-on` 回到上游。
4. 想核对状态：以[判断台账](90-ledger.md)及其分片为准。
5. 想质疑判断：按[贡献与反驳指南](../../CONTRIBUTING.md)使用卡片自己的证伪条件。
