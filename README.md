# ai-future · 未来沙盘推演

[English version](README.en.md)

## 这是什么

这是一个用底层规律推演未来趋势、再从中筛选可下注商机的公开知识档案。核心问题不是「预测得像不像」，而是：当某种能力变得丰富，价值和约束会迁移到哪里？每个可用判断都必须留下推理链、时间窗、证伪条件、领先指标和置信度。

这里不把任何人的预测当作论据。先从供需、人性、历史、技术扩散和社会规律独立推演；若结论与常见共识重合，会明确标注「与共识一致」。

## 怎么读

- **只想进入故事**：从 [近期图景](docs/zh/10-near.md) 开始，再沿着其中的 J-NNN 链接阅读。
- **想看完整方法**：阅读 [推演方法论](docs/zh/00-method.md)。
- **想看技术先后关系**：阅读 `docs/zh/05-tech-sequence.md`（首轮技术链仍在扩展中）。
- **想找可下注方向**：阅读 [商机候选](docs/zh/40-opportunities.md)。
- **想复盘依据**：打开 [判断台账](docs/zh/90-ledger.md)。

叙事文件负责让人读懂一条完整的推演链；台账负责保存判断的结构化元数据。叙事中引用 J-NNN，台账中记录它的时间窗、依赖和状态。远期判断依赖近期判断，但近／中／远只是粗粒度容器，不是严格日历排序。

## 判断编号 J-NNN 怎么用

每条判断分配全项目唯一的 `J-NNN` 编号（例如 `J-001`），中英文共用同一编号，编号不复用。阅读正文时，沿 J-NNN 跳到台账即可看到推理链、证伪条件、领先指标、置信度和 `depends-on` 依赖；某条判断被证伪时，其下游依赖必须重新审查，旧版本保留在 git 历史中。

## 判断总览表在哪里

总览表在 [docs/zh/90-ledger.md](docs/zh/90-ledger.md)；英文镜像在 [docs/en/90-ledger.md](docs/en/90-ledger.md)。商机候选的来源和闸门结果则集中在 [docs/zh/40-opportunities.md](docs/zh/40-opportunities.md)。

## Git 记录纪律

中英两棵树必须在同一次 commit 内同步更新。每次提交必须说明**改了哪条判断（J-NNN）以及依据什么新证据**，禁止使用没有信息量的流水账标题（如 `update docs`）。判断状态变化（`ACTIVE`、`HIT`、`FALSIFIED`、`REVISED`）应单独记录，便于用 git 回看推演演化。

## 当前边界

首轮内容从一条「生成变得便宜」的推演链开始；技术次序、组织、注意力与信任、资本、能源、人性需求等维度会继续补齐。未完成的维度必须留在台账的「显式缺口」中，不能假装全景已经完成。
