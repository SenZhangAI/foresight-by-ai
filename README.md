# ai-future · 未来沙盘推演

[English version](README.en.md)

## 这是什么

这是一个用底层规律推演未来趋势、再从中筛选可下注商机的公开知识档案。核心问题不是「预测得像不像」，而是：当某种能力变得丰富，价值和约束会迁移到哪里？每个可用判断都必须留下推理链、时间窗、证伪条件、领先指标和置信度。

商机不是唯一终点。项目也记录**结构性后果**：人与人如何协作、社会关系如何重排、人与 AI 如何形成关系，以及权力、意义和制度可能怎样变化。能赚钱的方向进入商机候选；没有付费者但有完整证据链的后果，和商机平级保留；证据不足的才标为「仅图景」。

这里不把任何人的预测当作论据。先从供需、人性、历史、技术扩散和社会规律独立推演；若结论与常见共识重合，会明确标注「与共识一致」。

## 从哪读起

六条路径，按你想要的东西挑一条——每条都直接落在文件上，不需要先读完方法论。

- **想先确认基础打得牢不牢** → 读[历史回顾：什么才能成为整个社会的风气](docs/zh/01-retrospect.md)。它不预测任何事，只回看 1956–2020 年已经发生的成功与失败，从中提炼五道「普及闸」，并当场用它们判自己：可视电话 1964 年为什么不行、2020 年为什么三个月就普及；New Coke 五道闸全过却在 79 天后撤回；以及本仓库自己的 C1 开篇场景，被这套闸判为不过。若要继续追问「这些规则真的比模型直觉或既有扩散理论多筛掉了什么」，读[历史伪样本外验证协议](docs/zh/02-historical-validation-protocol.md)：它先冻结候选池、留存集、角色隔离、基线与计分，再允许扩展案例。
- **想被一个故事击中** → 读推演链。[C1 · 生成变得免费之后，什么反而买不到了](docs/zh/chains/10-generation-becomes-free.md) 从一个下午讲起：六十套方案摆在面前，市场负责人却什么也决定不了。[C2 · 当数据不再免费：现实信号如何变成合同资产](docs/zh/chains/20-real-signals-become-contracts.md) 接着回答，一次真实观测凭什么值钱、又凭什么能写进合同。[C3 · 电子落地：算力的瓶颈从芯片移到电网、土地与许可](docs/zh/chains/30-power-land-and-permits.md) 把链条推到地面：当模型可以租、芯片可以买，真正排不到的是一台尚未制造的变压器和一场必须召开的听证会。[C4 · 具身智能：AI 要过普及闸，缺的是一具能承担后果的身体](docs/zh/chains/40-embodied-intelligence.md) 再把问题带回物理世界：模型会推理，不等于它能在别人的家、田地和病房里承担一次失败。[C5 · 生物与医疗：答案会先变便宜，证明与照护不会](docs/zh/chains/50-biology-medicine.md) 区分无限候选与必须对身体负责的证据链。[C6 · 教育与技能形成：讲解会泛滥，掌握仍要留下痕迹](docs/zh/chains/60-education-skill-formation.md) 追问当漂亮成品可外包之后，谁还能证明一个人真的会。[C7 · 技术先到，权力后到：能力出现次序如何穿过组织，才变成社会后果](docs/zh/chains/70-capability-to-social-consequences.md) 再把能力曲线接回组织、劳动、制度、资本与需求，拒绝从 benchmark 直接跳到失业率。[C8 · 芯片之前的晶圆厂：为什么气候风险咬住的是「已验证瓶颈」](docs/zh/chains/80-fab-materials-and-climate.md) 则向芯片上游回溯，区分矿产储量、名义多来源与真正可切换的已验证转化路径。
- **想要全景** → 按时间层读三篇正文：[近期 2026–2028](docs/zh/10-near.md) → [中期 2029–2032](docs/zh/20-mid.md) → [远期 2033–2040](docs/zh/30-far.md)。每篇横向覆盖六个维度，从技术、内容、信任一路走到权力与意义。**远期一篇请按图景读**：它背后的 12 张卡片（J-043–J-054）**置信度全部为「低（仅图景）」**，没有一张够格进商机候选，也不应被当作预测引用。
- **想找可下注的方向** → 直接读[商机候选](docs/zh/40-opportunities.md)：四条通过**机会耐久闸**的候选（谁付钱、付多少、为什么是现在、最强反方），外加一份「现在能吃、但会被同一股力量吃掉」的窗口清单。机会耐久闸回答「同一股力量能否把新稀缺再次自动化」；它不同于判断社会扩散的五道普及闸。
- **想检验我有没有胡说** → 打开[判断台账](docs/zh/90-ledger.md)。95 张判断卡片，每张写明推理链、时间窗、证伪条件、领先指标、置信度，以及它踩在哪几条上游判断之上。规则本身写在[推演方法论](docs/zh/00-method.md)：先看第 3 节的机会耐久闸，再看历史回顾中的五道普及闸。
- **想告诉我哪一条错了** → 读[如何反驳这里的判断](CONTRIBUTING.md)。它写明三件事：怎么用一条判断自己的证伪条件把它推翻、怎么补一个缺口维度、以及什么样的反对不会被采纳。

推演链和时间层正文**不是**同一批判断的两种切法，这一点过去写错了，现按实际覆盖更正：全部 95 张卡里，时间层正文引用 48 张，推演链引用 46 张，两者**重叠只有 15 张**；**仅链覆盖 31 张**，**仅时间层覆盖 33 张**，还有 **10 张两者都不覆盖**（J-008、J-012、J-015、J-016 只落在[技术能力演进链](docs/zh/05-tech-sequence.md)，J-066–J-071 只落在[历史回顾](docs/zh/01-retrospect.md)）。C4 已在相应论证处回链 J-073–J-078，并明确这些卡片自始按职业／组织层书写，不代表 C4 是唯一通过社会级普及闸的链。

**普及闸复核已回流正文（2026-09-20）**：历史批次 J-001–J-078 已逐条补记受众规模量级与闸一（规模）判定；本轮新卡 J-079–J-086 则在出生时直接应用同一判据。历史批次中**新改为 `REVISED` 的是 60 张**（原卡正文一字未删、编号不复用）；另有 J-004 此前已因另一原因标为 `REVISED`，所以 61 张历史卡带有事后收窄说明。历史批次有 4 张过闸；新卡全部不过闸一，因为其规模只是构造式影响面或制度／职业动作分母。**过闸只代表动作人口与频次通过规模筛选，不等于社会级预测**，低置信度和「仅图景」标签仍然优先限制引用。判据见[历史回顾 · 闸一](docs/zh/01-retrospect.md)，逐卡判定见[判断台账](docs/zh/90-ledger.md)。

技术能力的到达次序单独成篇：[技术能力演进链](docs/zh/05-tech-sequence.md) 只回答「什么先到、因此什么才成为可能」，不把社会后果提前写进去。

## 判断编号 `J-NNN` 怎么用

每条判断分配全项目唯一的 `J-NNN` 编号（例如 `J-001`），中英文共用同一编号，编号不复用；商机候选另用 `O-NNN`。

**正文里的每个编号都是链接**——点 [J-003](docs/zh/90-ledger.md#j-003--真正持久的稀缺是关于你的私有上下文的所有权与可用形态) 会直接落到台账里它那张卡片上，看到完整的推理链、证伪条件、领先指标、置信度和 `depends-on` 依赖。某条判断被证伪时，其下游依赖必须重新审查，旧版本保留在 git 历史中。

## 这套结构怎么读

近／中／远只是粗粒度容器，不是严格日历；精度由每条判断自己的时间窗承担。真正承担「序」的是卡片上的 `depends-on` 依赖链：更远的判断必须说明它踩着哪些近期或中期判断。

读者可以从一条远期判断开始，打开它的台账卡片，沿 `depends-on` 链逐个回溯上游，直到没有依赖；如果某条近期判断被证伪，就反向搜索哪些卡片依赖它，沿链逐层标记并重审受牵连的远期判断。这样，文档既保留可读的故事，也让推演的因果顺序可追踪。

## Git 记录纪律

提交前先跑 `python3 scripts/check.py`（零依赖）：它检查全库内部链接与锚点、判断卡片必填字段、**新卡独立的「受众规模」字段**（J-001–J-086 在迁移期只报警告，后续编号缺项则失败）、同一台账内重复 J 编号、置信度白名单、依赖边三处一致、中英文件名与判断卡编号集合对等（不比对正文内容），以及本 README 的[推演链登记](#推演链登记)表与磁盘链文件是否双向互相覆盖、登记表 Topic 是否被对应链文件的 H1 包含、按标题引用某条链时标题是否出自该文件自己的 H1、中英 README 声明计数的处数是否对等、两处「N 张判断卡片 / N 条独立推演链」计数是否等于仓库实际数量。它不能代替[发布前自检清单](docs/zh/90-ledger.md#十二发布前自检清单)里的价值判断项，也不裁定任何一条判断的质量——绿灯不是「可以发布」的依据，只是「这几件机械不变量当前成立」。改过脚本要补跑 `--self-test`（全部负例必须仍以正确的检查名报警）。中英两棵树必须在同一次 commit 内同步更新。每次提交必须说明**改了哪条判断（J-NNN）以及依据什么新证据**，禁止使用没有信息量的流水账标题（如 `update docs`）。判断状态变化（`ACTIVE`、`HIT`、`FALSIFIED`、`REVISED`）应单独记录，便于用 git 回看推演演化。

## 当前边界

首轮已有：一条技术能力顺序链、近／中／远三层图景、八条独立推演链、四条商机候选，以及台账里 95 张判断卡片。但「全方位图景」仍未完成——能源与物理基础设施由 C3 与 C8 覆盖，具身劳动由 C4 覆盖，生物医疗与教育／技能形成分别由 C5、C6 首轮覆盖，技术能力次序的组织、劳动、制度、资本与需求后果由 C7 首轮覆盖；地缘制度与法律产权仍只是部分覆盖，人与人协作方式、人与 AI 关系也仍需具体制度、组织与产品边界。芯片上游材料与气候耦合已有 C8 首轮覆盖，但仍缺跨企业工艺验证周期、多场址气候减产、保险条款与公用工程成本分摊的可比序列。已覆盖也不等于证据闭合：C7 缺跨国长期组织数据，医疗缺跨国部署与长期结局序列，教育缺跨国长期随机试验与资格互认序列。这些边界以显式条目保留在[台账第六节](docs/zh/90-ledger.md#六未覆盖维度缺口清单)，不会因为首轮有产出就被静默删除。
